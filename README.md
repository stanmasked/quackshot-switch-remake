# QuackShot Switch Remake (research prototype)

Homebrew-oriented research and implementation project targeting Nintendo Switch.

## Status

Early prototype. The portable v0.1 gameplay core is maintained separately while the repository is initialized; it has not yet been committed here. This repository will contain independently written source code, tests, and documentation—not original game assets.

## Original-game reference

The Sega Mega Drive / Genesis release is used solely as a reference to study observable game mechanics and metadata. ROM images, extracted graphics, music, sprites, and other copyrighted material are **not** to be committed to this repository.

## Development goals

- Portable, tested gameplay logic shared by desktop and Switch.
- Faithful movement and level interactions, validated against legally obtained reference gameplay.
- Independent rendering and user-interface code.
- Eventually build a homebrew `.nro` with devkitPro/libnx and SDL2; actual console validation is pending.
