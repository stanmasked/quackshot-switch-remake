# QuackShot Remake — этап №19: обратный ход параллакса и округление

В продолжение [этапа №18](REFERENCE_CITY_PARALLAX_RU.md) проверяется
**не новая графика оригинала**, а точность независимой процедурной
двухслойной SDL-сцены на Nintendo Switch.

## Проверка пикселей, а не только чисел

В программном SDL-рендерере `--parallax-smoke` создаются четыре
снимка полос на камерах 40, 41, 42 и 43 пикселя:

| Камера | Ближняя A | Дальняя B = floor(A/2) | Сдвиг A/B от прошлого |
| ---: | ---: | ---: | --- |
| 40 | 40 | 20 | начало |
| 41 | 41 | 20 | 1 / 0 |
| 42 | 42 | 21 | 1 / 1 |
| 43 | 43 | 21 | 1 / 0 |

Граничные пиксели исключены из сопоставления для предотвращения
ложного срабатывания из-за обрезки прямоугольников. Полосы должны
иметь достаточно цветовых границ: однотонная картинка не считается
успехом. После перехода на камеру 43 рендерер возвращается к 40;
строки обязаны побайтово совпасть с исходными.

## Доказательство на запущенном Switch-приложении

`tools/nexium_ci_probe.sh` добавляет ввод **A** (левый стик влево)
после продолжительного **D** (вправо). Мэппинг проверен по
`nexium-gui/src/controller_config.rs` NeXium.

Успех определяется исключительно CSV, созданным NRO внутри
эмулятора, а не успешной отправкой клавиш хостом:

- Пять и более отсчётов только в CITY TEST с включённым
  `QS_PHYSICS_REFERENCE_CITY`.
- Каждая пара содержит `distant == foreground // 2`.
- Не менее двух увеличений и двух уменьшений смещения камеры;
  падение от максимума до конечного отсчёта не менее 8 пикселей.
- Журнал движения содержит **оба** направления стика, наблюдаемое
  перемещение героя в обратном направлении более 8 пикселей,
  а также прежние проверки прыжка, выстрела, смены сцены и heartbeat.

Числовые отсчёты разрешают проверить передвижение объектов при
изменении камеры, но **не доказывают точность художественного фона**
или идентичность алгоритма оригинальной Mega Drive.

## Как воспроизвести

С devkitPro/SDL2 доступен Switch NRO, проверяемый в GitHub Actions
`NeXium Switch Emulator Runtime`. На Linux с SDL2:

```sh
cmake -S . -B build -DQS_BUILD_DESKTOP=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
SDL_VIDEODRIVER=dummy SDL_RENDER_DRIVER=software \
    ./build/quackshot-prototype --parallax-smoke
ctest --test-dir build --output-on-failure
```

Данные тестовой сцены — авторские прямоугольники. Образ Mega Drive,
исходные тайлы, музыка и оригинальная графика в сборку не включены.
Физическая Nintendo Switch этим тестом не проверяется.
