# QuackShot Remake — Stage204: офлайн-проверка и приватный запуск исследовательского комплекта

## Цель

После Stage203 комплект Genesis Plus GX содержит нужные модули и
опубликованные **только числовые** данные. Важно отделить:
1. **Подготовку и проверку** архива без оригинального ROM;
2. **Локальную приватную эмуляцию**, которая требует собственного ROM
   пользователя вне архива и не должна выполняться на публичном CI.

Stage204 создаёт `tools/genesis_private_bundle_launcher.py`,
распространяемый внутри архивного комплекта, и проверяет оба режима
без выхода оригинальных игровых данных в консоль.

## Режим preflight — не требует QuackShot ROM

После извлечения артефакта `genesis-plus-gx-rom-free-linux-x64`
в отдельный каталог на совместимой системе Linux x86-64:

```sh
cd /home/user/private-research/rom-free-emulator
PYTHONDONTWRITEBYTECODE=1 python3 tools/genesis_private_bundle_launcher.py \
  --preflight
```

Программа сверяет SHA-256 всего комплекта, исходного ядра, модулей,
четырёх числовых справочников и архивного VDP исследования, затем
проверяет соответствие libretro-бинарника **конкретному**
инструментированному Genesis Plus GX:

```text
4e3381cf5bfa7ff387bbe6887e7e31453bf4c8c85b295aa66d6d07d415dde7aa
```

Успех обозначается единственной строкой
`GENESIS_STAGE204_PRIVATE_BUNDLE_PREFLIGHT_PASS`.

При любой ошибке выдаётся только
`GENESIS_STAGE204_PRIVATE_BUNDLE_OR_RUN_REJECTED`, без приватных путей
или содержимого ROM. Preflight запрещает передавать `--rom` и
`--output` и ничего не запускает через эмулятор.

**Важное ограничение:** готовый бинарник из текущего GitHub Actions
собран для **Linux x86-64**. На macOS он напрямую не исполняется.
Простая локальная пересборка для другой ОС не даёт тот же SHA-256
и не считается воспроизведением архивного эксперимента.

## Режим локального оригинального исследования

Доступен только на машине, где пользователь самостоятельно сохранил
свой ROM. Исходный файл должен находиться вне каталога комплекта.
Пример:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 tools/genesis_private_bundle_launcher.py \
  --run --mode bracket \
  --rom "/home/user/private/QuackShot Starring Donald Duck.gen" \
  --output "/home/user/private-results/rom-bracket-stage204.json"
```

Режим `triplet` использует Stage200 и снимает сопоставление трёх
числовых источников по индексу libretro. Режим `bracket` использует
Stage201 и сравнивает VDP во время видеоколбэка и после того же
`retro_run`.

Перед чтением исходного ROM выполняется **полная** проверка
комплекта. Затем средство Stage192 проверяет SHA-256 и физическую
идентичность обоих локальных файлов (ROM и core). Проверка
повторяется до и после каждого запуска.

Приватный исходный ROM и результат дополнительно запрещено
размещать внутри любого Git-репозитория — включая отдельный соседний
репозиторий, не связанный с исследовательским комплектом. Проверяются
предки абсолютного расположения каждого приватного файла, а не только
каталог самого комплекта.

Приватный результат сохраняется единственным новым JSON вне
каталога комплекта, с правами `0600`, без перезаписи. В stdout
выдаётся лишь `GENESIS_STAGE204_PRIVATE_NUMERIC_RUN_PASS`.
При ошибках оригинальные пути и полученные измерения не выводятся.

## Что проверяет GitHub Actions

На публичном CI выполняется **только preflight** реального
собранного инструментированного Genesis Plus GX с числовыми
reference-файлами. Также запускаются одиннадцать ROM-free тестов на искусственных
данных: неверный SHA ядра, подмена манифеста, размещение оригинала
внутри архива, существующий выходной файл, ошибочный ROI, отсутствие
согласования фаз и маскировка приватных ошибок.

**Никакой оригинальный QuackShot ROM на GitHub Actions не запускается.**

## Предел достоверности

Успешный preflight означает только, что программная и бинарная среда
готова к отдельному приватному запуску. Это не доказывает, что
оригинальная координата RAM Y соответствует подошве персонажа,
не определяет размеры исходного хитбокса и не разрешает изменять
физику Nintendo Switch. Для этих выводов необходимы дополнительные
независимые измерения столкновений.
