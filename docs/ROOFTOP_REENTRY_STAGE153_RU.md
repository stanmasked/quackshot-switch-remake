# QuackShot Remake — этап №153: повторный вход в ROOFTOP TEST

Гостевая проверка выполняется поверх подтверждённой версии этапа №152. Изменяется только независимая диагностика, не физика, игровой мир или ранее утверждённые пороги CITY TEST.

1. Настоящие кнопки NeXium выбирают ROOFTOP, герой подходит к переключателю.
2. Жёлтый снаряд открывает шесть твёрдых клеток моста. Герой переходит по мосту.
3. START возвращает на карту. Повторный Nintendo A запускает тот же уровень.
4. NRO должна подтвердить, что перед выходом мост открыт, а после входа все шесть клеток снова пустые.
5. В новом посещении фиксируются минимум 45 последовательных кадров без FIRE и остаточных снарядов, а достижения сохраняются.

Первый CSV содержит покадровую траекторию двух посещений; второй — независимые переходы MAP/ROOFTOP. Оба записываются из NRO и не подменяются хостом. Проверяются два NeXium запуска, идентичность SHA-256 NRO, закреплённая контрольная сумма эмулятора и итоговое сравнение.

**Ограничение:** пока GitHub Actions не завершится успешно, гостевая проверка повторного входа считается неподтверждённой. Красный снаряд будет испытываться отдельно. Оригинальный ROM и защищённые ресурсы не публикуются.
