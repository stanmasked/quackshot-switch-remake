# QuackShot Remake — Stage178: защита повторного прыжка после приземления

## Цель

Новый оригинально-независимый тест проверяет игровой ввод при приземлении на верхнюю поверхность платформы. Игрок может удерживать Jump несколько кадров; приземление при **неотпущенной кнопке** не должно запускать новый прыжок. Только реальное отпускание и последующее новое нажатие образуют разрешённый фронт кнопки.

## 16 тестовых сценариев

Вручную задана безопасная платформа с верхом Y=160 и полом Y=208. Герой размером 12×20 стартует **над платформой**, на Y=115 с положительной вертикальной скоростью 3 px/кадр. Координата X находится на минимальном краевом перекрытии: левый или правый край, восемь дробных смещений (1/8, 2/8, …, 8/8 пикселя). Это авторская геометрия; оригинальные данные уровня не используются.

Для каждого случая выполняется:

1. **50 кадров непрерывного удержания Jump.** Первый фронт происходит ещё в воздухе, затем персонаж приземляется. После контакта, несмотря на удерживаемую кнопку, персонаж остаётся на Y=140 и вертикальная скорость равна нулю.
2. **Один кадр отпускания.** Герой остаётся на платформе, `previous.jump` становится 0.
3. **Новое нажатие Jump.** Сразу запускается прыжок: `grounded=0`, `vy<0`, положение Y меньше 140.
4. **Раннее отпускание и 80 кадров полёта/приземления.** Герой возвращается на ту же платформу без застревания.
5. **Ещё одно нажатие Jump.** Должен начаться второй разрешённый прыжок после нового приземления.

На каждом кадре два независимо инициализированных состояния должны совпадать по X/Y, Vx/Vy, grounded, HP и обеим фазам камеры. Нельзя провалиться сквозь платформу или получить лишний автопрыжок.

## Ограничения

Тест проверяет обработку фронта кнопки и целостность **нашего** ядра, а не оригинальный алгоритм QuackShot для Mega Drive. Приведённая платформа и координаты не извлечены из ROM. Исходные файлы игры, видеокадры, BK2, звуки и дампы RAM не публикуются. Производственный игровой код не меняется.

## Запуск

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
ctest --test-dir build -R reference_city_landing_jump_edge --output-on-failure
```
