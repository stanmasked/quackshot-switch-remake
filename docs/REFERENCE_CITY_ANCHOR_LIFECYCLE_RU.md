# Этап №26 — безопасное взаимодействие с красными якорями

Все сцены и координаты в этих тестах придуманы для технического
прототипа. Оригинальные ROM, графика, карты и музыка не включены.

## Обнаруженная ошибка

Когда персонаж за один дробный шаг падения пересекал две
почти совпадающие по высоте поверхности красных якорей,
прежний цикл выбирал **первый слот массива снарядов**.
Номер слота отражает историю создания снаряда, а не
порядок геометрических столкновений. В результате
персонаж мог оказаться на чуть более низкой опоре,
проигнорировав ближайшую верхнюю.

## Исправление

В самостоятельном профиле CITY TEST при движении вниз:

- Проверяются только активные, закреплённые **красные** якоря.
- Учитывается пересечение по X и прохождение через верхнюю
  плоскость якоря по Y в текущем шаге движения.
- Среди всех доступных опор выбирается минимальная
  мировая координата Y, то есть **верхняя опора**.
- Перестановка снарядов в массиве больше не меняет
  высоту приземления.
- Обычный прототип продолжает пользоваться старым
  порядком слотов без изменения.

В отдельном CTest \`reference_city_anchor_lifecycle\`
10 сценариев: конкурирующие якоря, перестановка слотов,
точное истечение таймера, переход на нижнюю опору,
уход с опоры, прыжок, неподходящий жёлтый снаряд,
выключенная опора, смена уровня и детерминированность.

## Важные ограничения

Это поведение **не выдается** за покадровую физику
оригинального QuackShot: точная логика закреплённых
плунжеров не восстановлена из инструкций Mega Drive.

Тесты C99 проверяют числовую геометрию; NeXium,
если успешно выполнен в CI, подтверждает базовую работу
сборки NRO в эмуляторе, но не автоматическое исполнение
всех 10 тестовых случаев внутри консольного процесса.
