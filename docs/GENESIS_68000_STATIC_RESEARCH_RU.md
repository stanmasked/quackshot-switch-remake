# QuackShot: карта CPU 68000 исходного Mega Drive ROM

Дата: 17 октября 2026. Все наблюдения получены статическим чтением
единственного приватного пользовательского образа. Оригинальные байты
игры, музыка, карты, спрайты и ROM в GitHub **не публиковались**.

## Привязка к образу

Профиль: research/reference_profiles/user_rom_2026-10-17.json

SHA-256 оригинального пользовательского ROM:
30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34

Размер: 524288 байт. Контрольная сумма заголовка совпадает с
расчётной, но это **не доказывает неизменность оригинальной игры**.
Заголовок упоминает русскую версию. Происхождение локализации
самой контрольной суммой не подтверждается.

## Проверенные значения 68000

| Элемент | Значение |
| --- | --- |
| Начальный SSP | 0x00FFFF00 |
| Точка старта Reset PC | 0x000206 |
| Общий обработчик исключений | 0x000200 |
| Количество векторов с общим обработчиком | 54 |
| CHK-исключение, вектор 6 | 0x000522 |
| Прерывание уровня 6, вектор 30 | 0x00052A |
| TRAP 0 / 1 / 2 | 0x00158C / 0x0017B2 / 0x001AB2 |
| TRAP 3 / 4 / 5 | 0x001AFC / 0x001D1C / 0x0021B4 |

Уровень IRQ 6 обычно связывают с VBlank. Наличие адреса
обработчика **не является свидетельством произошедшего VBlank**.

## Аппаратные обращения — статические кандидаты

Инструмент tools/rom_static_map.py распознаёт строго определённые
формы TST, MOVE, JMP, JSR с абсолютными 32-битными адресами,
включая MOVE с immediate-значениями и регистрами Dn.

Целевые аппаратные области:
- 0xA10000–0xA1001F — регистры Genesis I/O;
- 0xA14000–0xA14003 — TMSS;
- 0xC00000–0xC0001F — VDP/PSG.

Для образа нашлось **21 совпадение с кодовыми шаблонами**.
Кандидаты, представляющие интерес для управления:

| ROM-смещение | Статически распознанное обращение |
| --- | --- |
| 0x000206 | TST.L по адресу 0xA10008 |
| 0x00020E | TST.W по адресу 0xA1000C |
| 0x000300 | TST.W по адресу 0xC00004 |
| 0x001FD8 | MOVE.B immediate → 0xA10003 |
| 0x002114 | MOVE.B immediate → 0xA10003 |
| 0x002120 | MOVE.B из 0xA10003 в Dn |
| 0x00212C | MOVE.B immediate → 0xA10003 |
| 0x002138 | MOVE.B из 0xA10003 в Dn |

**Ограничение:** опкоды могли совпасть с числами внутри данных.
Статический поиск не доказывает, что эти инструкции исполняются.
Это гипотезы для CPU breakpoint, а не измеренная механика.

Полная карта без оригинальных байтов сохранена в
research/observations/user_rom_68000_static_2026-10-17.json.

## Воспроизведение без выгрузки ROM

Выполнять только локально, в каталоге репозитория:

    python3 tools/rom_report.py "/private/QuackShot Starring Donald Duck.gen" --profile research/reference_profiles/user_rom_2026-10-17.json

    python3 tools/rom_static_map.py "/private/QuackShot Starring Donald Duck.gen" --profile research/reference_profiles/user_rom_2026-10-17.json --output /tmp/quackshot-68000-static.json

Программа не делает сетевых запросов и сохраняет лишь числовые метаданные.
При несоответствии профилю отчёт не публикуется. GitHub Actions
использует только самостоятельно сконструированные тестовые ROM-фикстуры.

## Дальнейшее исследование игры

1. В локальном эмуляторе Mega Drive с 68000-отладчиком (BlastEm или MAME)
   открыть тот же приватный ROM, не отправляя его в GitHub.
2. Проверить Reset PC = 0x206 и выполнение адресов 0x2120 и 0x2138
   в реальном цикле чтения контроллера.
3. Последовательно воспроизвести отсутствие ввода, движение вправо,
   прыжок, стрельбу; записать фактически выполненные инструкции,
   VBlank и изменённые адреса RAM.
4. По наблюдаемым RAM-адресам подтвердить координаты, скорость,
   флаги прыжка и количество вантузов.
5. Сравнить кадр за кадром с числовой трассой нашего Switch-прототипа
   (quackshot-motion.csv) после выравнивания системы координат.

Ни скорость ходьбы, ни высота прыжка из настоящей QuackShot
пока **не измерены**. Тестовые константы нашего Switch-движка
сохраняются без объявления их эталонными.
