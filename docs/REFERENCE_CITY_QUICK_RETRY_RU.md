# QuackShot Remake — этап №71: быстрый повтор попытки CITY TEST

## Игровая механика

В собственном экспериментальном уровне **CITY TEST** добавлен
быстрый перезапуск для тренировок и гонок на время.

**Nintendo Switch: R + Start**, клавиатура SDL2: **Left Shift + Escape**.
Нажатие Start без удержания R продолжает возвращать на карту уровней.

Комбинация действует только на этапе CITY TEST, запущенном с
`QS_PHYSICS_REFERENCE_CITY`. Базовый прототип, RUINS TEST и ROOFTOP
TEST используют прежнее действие Start.

## Что происходит при быстром повторе

Игрок без промежуточного входа в меню сразу появляется в начале
CITY TEST (X=40, Y=188). Через существующий `qs_begin_stage()`
сбрасываются:

- счётчик времени текущей попытки;
- заработанная контрольная точка, её промежуточное время и
  сравнение с прежним рекордом;
- два коллекционных жетона и текущие условные очки;
- снаряды, отложенные выстрелы, враги, предметы и
  состояние движения/камеры;
- потерянные сердца и временная неуязвимость.

При этом **лучшее время полного прохождения, лучший split,
лучший результат по жетонам, открытое оружие и отметки
пройденных уровней сохраняются** в игровой сессии.

Кадр с R + Start не выполняет движение, стрельбу,
подбор предметов или столкновение с врагом. Длительное
удержание Start не вызывает множество быстрых повторов:
обрабатывается только новая фронтальная команда Back.
После отпускания и нового нажатия команду можно повторить.

Если герой уже достиг выхода в CITY TEST, подтверждённый
финиш имеет приоритет и вместо быстрого повтора происходит
обычный переход на карту с записью времени. Так игрок
не теряет справедливо завершённую попытку.

## Проверки

В `tests/test_reference_city_quick_retry.c` создано
**16 регрессионных сценариев** и **500-кадровая
детерминированная последовательность**. Проверяются
сброс и сохранение данных, R+Start с другими одновременно
зажатыми кнопками, отсутствие повторного срабатывания
при удержании, обычный Start, финиш, ошибка координат,
появление рядом с врагом/предметом и изоляция прототипа.

Проверка `CITY_QUICK_RETRY_SDL_PASS` сравнивает настоящие
растровые кадры SDL2: результат R+Start должен точно
совпадать со сценой новой попытки, а исходный кадр
с прогрессом обязан отличаться. Отдельно проверяется
нулевое время, два несобранных жетона, сохранение
личного рекорда, отсутствие повторного сброса при
удержании и возвращение в меню по обычному Start.

Новые тесты зарегистрированы в CMake/CTest и обязательны
в GitHub Actions для GCC/Clang/SDL2. Отдельные workflow
проверяют Nintendo Switch NRO и NeXium.

Всё содержимое CITY TEST — собственная тестовая геометрия
и алгоритмы, **без опубликованного ROM или оригинальной
графики/музыки QuackShot**. Результат CI можно считать
подтверждённым только после завершения workflow
соответствующего итогового коммита.
