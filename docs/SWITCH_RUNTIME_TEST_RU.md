# Nintendo Switch — протокол проверки запуска

Версия: технический прототип без оригинальных игровых ресурсов.

**Статус:** GitHub Actions компилирует NRO для libnx/SDL2 и проверяет
структуру файла. Это **не подтверждает** запуск на настоящей консоли.
До испытания в Switch-среде статус runtime остаётся «не проверено».

## Как получить NRO

В GitHub Actions откройте последний успешный запуск
«Nintendo Switch NRO (prototype)» для PR №2. Скачайте артефакт
quackshot-switch-prototype-nro и распакуйте quackshot-prototype.nro.

Для уже настроенной homebrew-среды Nintendo Switch файл может находиться
по пути sdmc:/switch/quackshot-prototype.nro. Запускайте через Homebrew Menu.
Это homebrew NRO, не NSP/XCI и не эмулятор Mega Drive.
Не изменяйте настройки безопасности консоли ради теста.

## Проверки

1. **Загрузка:** экран появляется без немедленного возврата в Homebrew Menu.
2. **Карта:** три цветные строки; крестовина переключает, A открывает сцену.
3. **Движение:** левый стик/крестовина перемещают героя.
4. **B:** прыжок; **Y:** выстрел; **R:** ускорение.
5. **X:** меняет тип вантуза после получения тестового усиления.
6. **Plus:** возвращает к карте.
7. **Устойчивость:** переходы и движение не вызывают зависаний/краха.

Все изображения — временные геометрические формы, без оригинальных спрайтов.
Локации искусственные, не извлечённые из QuackShot.

## Протокол наблюдений

Укажите тип консоли/эмулятора и версию, способ запуска, дату теста,
реакцию кнопок, что показано на экране, длительность работы и
подробности ошибки. При необходимости — снимок геометрического экрана
без персональной информации. Не прикладывайте системные ключи, ROM или
файлы приватной прошивки.

Результат «успешно»: сцены рендерятся, кнопки работают,
переходы карта ↔ сцена работают и зависаний нет.
Незавершённый тест нельзя обозначать как успешный.

## Что покрывает GitHub Actions

- Debug/Release модель геймплея и её регрессии;
- реальный SDL2 software/dummy рендер и считывание пикселей;
- повторяемость кадров при одинаковом управлении;
- виртуальный SDL2-геймпад: B, Y, R, направление и левый стик;
- кросс-компиляция libnx + SDL2 и проверка NRO0/ASET/NACP.

**Граница достоверности:** SDL2 dummy и виртуальный геймпад на Linux
не заменяют драйвер Nintendo Switch и запуск на устройстве.
