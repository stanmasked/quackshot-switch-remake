# QuackShot Remake — этап №87: единый маршрут CITY TEST

Тест начинается из обычной стартовой позиции X=40, Y=188
с тремя игровыми противниками, двумя предметами, пропастью,
навесами, вертикальной стеной, разрушаемым ящиком и контрольной точкой.

После `qs_begin_stage` тест не изменяет координаты персонажа,
ускорение, скорость, противников, карту, здоровье или бонусные флаги.
Единственный источник игрового движения — реальные команды `QsInput`.
Управление детерминированное и использует координаты препятствий
для выбора времени прыжка, стрельбы по ящику и направления после трамплина.

Успех фиксируется только при наблюдении в этом порядке:
1. Прыжок через пропасть.
2. Прыжок через высокий участок и активация контрольной точки.
3. Выстрел с разрушением ящика.
4. Отскок от пружины, получение воздушного сердца.
5. Посадка на одностороннюю площадку и выход на карту с cleared[0]=1.

После завершения тест повторно входит в CITY TEST через экран карты,
проверяя сохранение рекордов и очистку данных попытки. Сценарий с паузой
сравнивается с таким же прохождением без паузы; дополнительная проверка
сравнивает независимые повторы движения.

Тест изолирован от штатного прототипа и не использует оригинальную
игру, ROM, музыку или её графические материалы.
