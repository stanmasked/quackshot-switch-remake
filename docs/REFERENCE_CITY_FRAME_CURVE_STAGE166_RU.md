# QuackShot Stage166 — покадровая калибровка CITY TEST (ROM-free)

## Назначение

Существующие проверки `test_reference_city.c` сверяли несколько якорных точек, но не каждый кадр между ними. Новый тест `test_reference_city_curve_lockstep.c` использует независимо написанный **целочисленный 16.16 оракул** и проверяет, что opt-in профиль `QS_PHYSICS_REFERENCE_CITY` не дрейфует от этой математической модели.

Контрольная исходная точка тестовой сцены — X=61; она выставляется тестом, а не воспроизводит оригинальные тайлы. Используются только измеренные константы ускорения `0x2800`, предельной скорости `0x1A000`, импульса прыжка `-192000/65536`, гравитации `0x3200` и 15 кадров удержания начальной скорости.

## Проверяемые сценарии

- 80 последовательных игровых кадров ходьбы: 20 вправо, 20 влево, свободное торможение, конфликт LEFT+RIGHT, повторный короткий ввод RIGHT и остановка.
- 25 кадров короткого прыжка A на 1 кадр.
- 25 кадров промежуточного прыжка A на 8 кадров.
- 25 кадров длительного прыжка A на 50 кадров (в измеряемом окне первые 25).

В каждом кадре сравниваются скорость и **накопленная позиция**, а не только её итог. Для `float` допускается погрешность 0,035 пикселя и 0,00015 пикселя/кадр; сам целочисленный оракул шагает точно без округлений промежуточных значений. Проверяется, что персонаж остаётся в игровой сцене, а прыжковые прогоны выполняются без коллизии до конца 25-кадрового окна.

## Границы доказательства

**Не утверждается**, что разворот, конфликт направлений и восьмикадровый прыжок уже сверены с оригинальным QuackShot: это контроль математической модели, а не новая приватная запись ROM. Конкретные физические константы подтверждены лишь для одной точки оригинального городского уровня. Столкновения с оригинальными объектами, Dash, повреждения, поведение на других уровнях и полноценное воспроизведение BK2 не проверяются этим тестом.

Для запуска без оригинального ROM:

```sh
cmake -S . -B build -DQS_BUILD_DESKTOP=OFF -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
ctest --test-dir build -R reference_city_frame_curve_lockstep --output-on-failure
```

Этот новый тест попадает в стандартную матрицу GCC/Clang Debug/Release через `core-tests.yml`. Код игры, исходные ресурсы и профиль по умолчанию не изменяются.
