# QuackShot Remake — этап №158: открытый жёлтый мост сбрасывается при входе

## Цель и рамки

После двух красных отрицательных выстрелов и настоящего открытия ROOFTOP-моста жёлтым снарядом, подтверждённого Stage157, проверить **живое возвращение на карту и третий вход** в ту же тестовую сцену. Мост должен вновь стать непроходимым: `bridge_before=1 → bridge_after=0` на фактическом событии `MAP→ROOFTOP`, и все шесть клеток должны оставаться пустыми не менее ста подряд кадров после входа. При этом ранее разблокированное красное оружие и выбранное жёлтое не должны пропасть.

## Гостевой маршрут

В NeXium настоящие виртуальные кнопки проходят CITY red pickup, две независимые красные атаки через два посещения, переключение на жёлтое кнопкой Nintendo X, жёлтое попадание и открытие моста 6/6. Затем реальный START выходит из **открытого** ROOFTOP в MAP; Nintendo A снова выбирает ROOFTOP. После входа контроллер не отправляет новых игровых действий и наблюдает исходные кадры NRO в состоянии 0/6.

Это **не** эмуляция/подмена состояния героя. Ключевое доказательство — шесть событий реальных переходов NRO `CITY→MAP→ROOF→MAP→ROOF→MAP→ROOF`, кадры которых сопоставляются с неизменёнными `quackshot-rooftop-transitions.csv`, `quackshot-rooftop-guest.csv` и `quackshot-rooftop-weapon.csv`.

## Строгие проверки

- Полный Stage157 RED→RED→YELLOW повторно подтверждается для первых двух посещений (два настоящих красных снаряда, реальная смена оружия, открытие мостовых клеток жёлтым снарядом).
- Выход через START фиксирует мост **открытым** (6/6) и выбранное жёлтое оружие; третий вход через Nintendo A обязан закрыть его 0/6, не потеряв красную разблокировку и остальные достижения.
- Начиная с самого первого кадра третьего ROOFTOP, как минимум 100 подряд кадров подтверждают 0/6, отсутствие старых снарядов и новых нажатий FIRE или смены оружия.
- Два независимых прогона обязаны использовать идентичную сборку NRO и закреплённую контрольную сумму NeXium. Текстовые сообщения хоста никогда не заменяют NRO-журналы: их номера кадров должны буквально совпадать с настоящими кадрами события.
- Негативные тесты должны отвергать фальшивый вход, ложный статус моста, потерю оружия, поддельные кадры, старые выстрелы и отсутствие достаточного времени наблюдения.

## Команды проверки

```bash
python3 -m unittest discover -s tests -p test_rooftop_yellow_reset.py
cmake -S . -B build-stage158 -DQS_BUILD_DESKTOP=OFF
cmake --build build-stage158 --parallel 2
ctest --test-dir build-stage158 --output-on-failure -R rooftop_yellow_bridge_reset_guest_protocol
```

Для настоящей NRO требуется [NeXium ROOFTOP Yellow Bridge Reset](../.github/workflows/nexium-rooftop-yellow-reset.yml).
