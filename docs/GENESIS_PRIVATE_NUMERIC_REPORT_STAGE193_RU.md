# QuackShot Remake — Stage193: обязательная проверка числового свидетельства до публикации

## Зачем

Stage192 уже подтверждает неизменность двух приватных входных файлов (ROM и
Genesis Plus GX) на протяжении трёх повторов. Однако раньше Stage188 мог
записать числовой JSON, который затем Stage189 отказался бы принимать.
Кроме того, вывод без `--output` попадал в stdout, а явный вывод мог быть
размещён в открытом дереве репозитория либо перезаписать прежний отчёт.

Stage193 закрывает именно этот разрыв. Реального запуска оригинальной игры
в этом PR нет, изменение физики Switch не выполняется.

## Безопасный протокол

`genesis_city_fractional_fall_probe.py` теперь требует абсолютный
`--output`, не пишет JSON в stdout и перед записью вызывает **сам**
`city_fractional_witness_comparison.compare()` из Stage189.

Stage189 проверяет точную схему, оба SHA-256, числовые значения и
хронологию, фазы RAM/video, арифметику длительностей, отсутствие
запрещённых полей (RAW RAM, ROM, покадровых данных). При нарушении
любого условия файл отчёта не создаётся.

Новый `tools/private_genesis_report_output.py` требует:
- абсолютный путь с расширением `.json` **за пределами репозитория**;
- уже существующую локальную папку, не являющуюся символической ссылкой;
- **новое** имя файла: существующий отчёт или symlink никогда не заменяется;
- завершённую проверку Stage189 *до* появления файла на диске;
- запись временного файла с правами `0600`, `fsync` и атомарную
  публикацию через исключительное создание ссылки на готовый файл.

Ошибка системного вызова не раскрывает приватный путь. Содержимое
отчёта остаётся исключительно числовым. Существование файла и его
валидность **не являются** независимым доказательством запуска ROM:
сравнение по-прежнему имеет статус
`USER_NUMERIC_WITNESS_NOT_INDEPENDENTLY_ATTESTED`.

## Локальный запуск

Сначала создайте отдельную приватную папку вне git:

```bash
mkdir -p "$HOME/private-quackshot-reports"
chmod 700 "$HOME/private-quackshot-reports"
python3 tools/genesis_city_fractional_fall_probe.py \
  --rom "$HOME/private-games/QuackShot.gen" \
  --core "$HOME/private-cores/genesis_plus_gx_libretro.so" \
  --output "$HOME/private-quackshot-reports/fractional-stage193.json"
```

Этот запуск возможен только с **тем же SHA-256 ROM и тем же бинарником
Genesis Plus GX**, что были закреплены предыдущими измерениями.
Оригинальный ROM и бинарник ядра не должны помещаться в публичный
репозиторий. При несовпадении SHA-256 сохранение не происходит.
Повторный запуск требует другого имени отчёта (без перезаписи
предыдущего).

`Stage189` уже выполнен перед сохранением; для дополнительной
локальной сверки можно вызвать:

```bash
python3 tools/city_fractional_witness_comparison.py \
  --fractional-witness "$HOME/private-quackshot-reports/fractional-stage193.json" \
  --out "$HOME/private-quackshot-reports/fractional-comparison.json"
```

Это не делает сравнение независимой аппаратной аттестацией или
подтверждением коллизий оригинальной карты.

## ROM-free проверка

Тест `test_private_genesis_report_output.py` моделирует корректно
оформленное, но полностью вымышленное свидетельство; проверяет права
`0600`, запрещённую запись в публичный source tree, отказ при
неправильных фазах и SHA, запрещённых полях, конфликтующих
длительностях, символических ссылках и существующем файле.

В тестах нет оригинальных ROM, BK2, RAM, видео, звука либо приватных
путей пользователя. Публичная игра, физика C99 и NRO не затронуты.
