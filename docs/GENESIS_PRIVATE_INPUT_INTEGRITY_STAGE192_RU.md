# QuackShot Remake — Stage192: неизменность приватных исходных файлов

## Проблема

Stage188–191 защищают значения измерений, RAM sampling phase и кратность
видеоколбэков. Но без проверки файлов во время серии запусков исходный ROM
или бинарник Genesis Plus GX могли незаметно измениться **между** прогоном
`idle`, `right` и `right_repeat`. SHA-256 ядра, вычисленный только
после всех запусков, не устанавливает неизменность на их протяжении.

## Новая защита

`tools/private_genesis_input_guard.py` проверяет два **локальных** файла:

- оригинальный ROM: SHA-256
  `30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34`;
- бинарник Genesis Plus GX: SHA-256 берётся из трёх согласованных
  публичных **числовых** свидетельств проекта через
  `reference_evidence_integrity.validate`, а не из произвольного
  переданного пользователем хэша.

Для каждого файла проверяется тип (обычный файл, без символической ссылки),
SHA-256 и локальная идентичность файла (устройство, inode, размер,
mtime_ns и ctime_ns). Снимок повторяется **до и после** каждой из трёх
итераций `retro_run`-серии; дополнительно проводится проверка до
загрузки core, после чтения ROM и непосредственно перед формированием
выходного отчёта.

Проверка после серии выполняется через `finally` даже при исключении
из libretro. Изменение содержимого или замена файла при прежнем SHA
останавливает исследование. При изменении в ходе чтения SHA-256
проверка также завершается отказом.

Эти проверки относятся к целостности файлов, а не к подтверждению
внутренней работы Motorola 68000, VDP, отсутствия побочных эффектов core
или подлинности предоставленного извне JSON.

## Запуск (только доверенная локальная машина)

Используйте **именно** локальную копию закреплённого бинарника
Genesis Plus GX и **собственный** оригинальный ROM. Исходные файлы
должны оставаться вне публичной рабочей копии репозитория.

```bash
python3 tools/genesis_city_fractional_fall_probe.py \
  --core /private/cores/genesis_plus_gx_libretro.so \
  --rom /private/games/QuackShot.gen \
  --output /private/reports/qs-fractional-stage192.json

python3 tools/city_fractional_witness_comparison.py \
  --fractional-witness /private/reports/qs-fractional-stage192.json \
  --out /private/reports/qs-fractional-comparison.json
```

Первый вызов вычисляет только краткое числовое резюме, а не
RAW RAM, видео или копию ROM. Если ядро или версия игры отличается от
закреплённой, он **должен завершиться с ошибкой**; нельзя обходить
защиту подменой эталонных SHA. Второй шаг принимает только минимально
разрешённую схему и сохраняет статус
`USER_NUMERIC_WITNESS_NOT_INDEPENDENTLY_ATTESTED`, а не фиктивную
криптографическую аттестацию.

Не загружайте в публичный PR даже приватные пути файлов,
необработанные RAM-дампы, ROM, BK2, изображения или звуковые ресурсы.
Полученный отчёт содержит числовые пороги и SHA — проверяйте его
отдельно перед внешней передачей.

## ROM-free CI и ограничения

`tests/test_private_genesis_input_guard.py` проверяет постоянные
локальные файлы, неправильные SHA, подмену байтов без изменения длины,
замену теми же байтами через другой inode, символические ссылки,
порядок 6 внутренних проверок вокруг 3 искусственных прогонов,
исключение core и изменение файла непосредственно во время
искусственного запуска.

Никакие реальные ROM и libretro core в этих тестах не используются.
Физика C99, NRO и игровые ассеты не изменены. Этот PR не содержит
нового измерения дробного Y оригинальной игры.
