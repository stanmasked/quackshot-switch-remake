# QuackShot Remake — этап №81: воздушное сердце

Самостоятельно нарисованный бонус над пружинным трамплином CITY TEST:
координаты X=1152, Y=96, область контакта 10×10 пикселей.
Обычный прыжок измеренного городского профиля не достигает бонуса;
пружина с фиксированным импульсом −8 px/tick позволяет подняться к нему.

* Первое касание после выжитого кадра даёт **не более одного сердца** (максимум 3).
* Бонус расходуется даже при полном здоровье, не превращается в накопительный источник лечения.
* Коллекция хранится один раз в попытке и не сбрасывается после смерти/падения в яму или возрождения на контрольной точке.
* Пауза полностью замораживает бонус. Быстрый рестарт и выход на карту сбрасывают его.
* Профиль обычного прототипа, начисление 500+500 за два наземных маяка и личные рекорды не меняются.
* Отрисовка использует только процедурные прямоугольники, без данных оригинальной игры.

## Проверки

`tests/test_reference_city_air_reward.c`: 14 C-сценариев + два идентичных потока 420 кадров.
`quackshot-prototype --smoke`: ARGB8888-проверка изображения до и после получения, после нового захода, отдельно от обычного прототипа.
`ctest --output-on-failure`: обязательное задание portable CI.

До успешного завершения GitHub Actions не считать проверки нового коммита подтверждёнными.
