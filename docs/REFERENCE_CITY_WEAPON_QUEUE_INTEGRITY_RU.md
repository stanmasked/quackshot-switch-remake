# QuackShot Remake — этап №54: целостность выбранного оружия и отложенного выстрела

## Причина

В самостоятельно разработанном CITY TEST тип снаряда фиксируется
при нажатии Fire, а сам снаряд появляется на следующий симуляционный
такт. До этапа №54 повреждённые целочисленные значения полей
`red_unlocked`, `weapon`, `pending_reference_shot` и
`pending_reference_red` могли считаться истинными флагами либо
приводить к непредусмотренному красному снаряду. В частности,
`INT_MAX` в поле отложенного выстрела считался настоящим событием.

## Новый защитный проход

`sanitize_city_weapon_queue()` выполняется в `qs_step()` перед
обработкой Back, завершения этапа, переключения оружия и отправки
отложенных снарядов. Он работает только в
`QS_PHYSICS_REFERENCE_CITY` для CITY TEST.

- `red_unlocked` нормализуется до 0/1: неположительные значения
  становятся 0, положительные — 1.
- Недопустимое `weapon` заменяется безопасным `QS_YELLOW`.
  Выбранный красный вариант без разблокировки тоже становится жёлтым.
- Только значение 1 в `pending_reference_shot` является настоящей
  отложенной командой. Иначе оба поля отложенного события очищаются.
- Недопустимое `pending_reference_red` очищается. Красный отложенный
  выстрел без разблокировки не допускается.
- **Корректная задержанная команда не теряет цвет** при переключении:
  Fire на красном оружии, затем Change на жёлтом выдаёт красный
  снаряд ровно в запланированный следующий кадр. Обратный порядок
  для жёлтого работает симметрично.

Новый проход не меняет обычный профиль `QS_PHYSICS_PROTOTYPE`
и не добавляет в публичный репозиторий оригинальные игровые материалы.

## Проверки

В `tests/test_reference_city_weapon_queue_integrity.c` находятся
15 сценариев: повреждённые разблокировки, значения оружия, недопустимые
флаги очереди и цвета, одиночный новый Fire на месте повреждённой
очереди, Back, Fire+Change, оба цвета латча, изоляция базового профиля
и **500-кадровое детерминированное воспроизведение**.

`WEAPON_QUEUE_SDL_PASS` читает пиксели HUD реального SDL2:
повреждённое состояние переходит в жёлтый индикатор, корректная
разблокировка — в красный, а смена оружия в кадре выпуска красного
отложенного снаряда снова показывает жёлтый индикатор.
CI обязан проверить этот маркер вместе с прочими тестами.

Статусы CTest, сборки Nintendo Switch NRO и запуска в NeXium
подтверждаются только по итоговым GitHub Actions того же коммита.
Физическая консоль Nintendo Switch не тестируется.
