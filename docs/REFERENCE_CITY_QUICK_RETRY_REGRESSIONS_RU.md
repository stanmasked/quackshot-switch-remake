# QuackShot Remake — этап №73: согласование старых проверок с новыми механиками

## Выявлено в CI этапа №72

После добавления R + Start (этап №71) и разрушаемого ящика
(этап №72) матрица Clang Debug сообщила о трёх неуспешных
CTest из 52. Проверки новых механик, включая сам ящик и
быстрый повтор, при этом проходили.

Причины обнаруженных ошибок находятся в **предыдущих
тестовых сценариях**, где использовались уже изменившиеся
условия:

1. `stage_finish_chord_priority`: тест старого выхода из
   незавершённого уровня нажимал Back **вместе с R**. Теперь
   это отдельная команда мгновенного повторения CITY TEST.
   Для проверки прежнего выхода оставлен Back без R; приоритет
   уже достигнутого финиша перед полной комбинацией сохранён.
2. `reference_city_numeric_map_reentry`: прежний тест
   повреждённых координат ожидал переход на карту после
   Back+R. Для чистого аварийного выхода оставлен Back
   без R. Отдельные проверки R+Start продолжают проверять
   безопасный быстрый повтор.
3. `reference_city_fractional_timeline`: независимый
   тест хронологии выстрелов использует плоскую сцену
   без посторонних препятствий. После появления нового
   ящика скоростной снаряд начал закономерно попадать в
   препятствие. В этой **изолированной тестовой сцене**
   объект теперь отключён: реальное его разрушение и
   взаимодействие со снарядами отдельно проверяются
   `reference_city_breakable_crate` и `CRATE_SDL_PASS`.

SDL2-сценарий `NUMERIC_TRANSITION_SDL_FAIL` также был
основан на Back+R при ожидании карты. Теперь он упражняет
обычный Back. Это сохраняет жёсткую проверку очистки
снарядов, безопасного восстановления координат и
отсутствия ложного завершения уровня.

**Игровая физика, поведение R+Start, обработка выстрелов,
статистика времени и разрушаемый ящик на этом этапе
не переписываются.** Исправлены только устаревшие
исследовательские сценарии и комментарии к ним.

## Подтверждение

GitHub Actions должны отдельно подтвердить матрицу
GCC/Clang Debug/Release, SDL2 smoke с CTest, Switch NRO
и запуск NeXium на **итоговом коммите этапа №73**.
До завершения этих запусков нельзя утверждать, что
регрессии полностью устранены.

Как и на предыдущих этапах, публичный репозиторий не
содержит оригинальный ROM, спрайты, карты или музыку.
