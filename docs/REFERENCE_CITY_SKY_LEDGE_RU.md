# QuackShot Remake — этап №84: односторонняя воздушная площадка

Новая оригинальная площадка расположена на X=1176..1204, с поверхностью Y=144.
Это небольшая опора на завершающем участке экспериментального CITY TEST.

При движении сверху вниз герой может приземлиться; при подъеме снизу
и боковом прохождении препятствие отсутствует. При одновременном
пересечении красного якоря и площадки побеждает верхняя опора.
Обычный прототип, пружина и воздушное сердце не меняются.

C-тест test_reference_city_sky_ledge.c проверяет границы, посадку,
стационарное положение, прыжок, проход снизу, красный якорь,
пружину, паузу, рестарт, обычный прототип и 480 синхронных кадров.
Проверка SDL2 считывает точные пиксели в двух фазах камеры.

До успешного завершения новой матрицы GitHub Actions код нельзя
считать проверенным на Nintendo Switch или в NeXium.
