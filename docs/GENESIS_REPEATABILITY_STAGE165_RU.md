# Stage165 — независимая повторяемость числовых трасс Mega Drive

Этот этап **не** является доказательством завершённого порта QuackShot и **не** воспроизводит BK2. Его задача — проверить, повторяется ли одна и та же числовая физика при независимых холодных запусках Genesis Plus GX с *локальным* оригинальным ROM.

## Что проверяется

- Для каждого сценария выполняется **2–4 независимых холодных запуска** (`retro_init`, `retro_load_game`, `retro_unload_game`, `retro_deinit` в каждом запуске).
- Для каждого запуска выполняется 2320 кадров, а в окне `[2069, 2191)` сравниваются **каждый кадр и все восемь числовых полей** X/Y/VX/VY (целая и дробная части 16.16).
- Исходный набор из семи сценариев дополнен **разворотом RIGHT→LEFT** (20 + 20 кадров) и **прыжком A на 8 кадров**. Новые варианты пока проверяют только повторяемость, *не* совпадение с ещё не измеренным эталонным результатом.
- Неизменное состояние до первого действия, точное количество считанных нажатий, наблюдения ускорения/торможения и два ранее измеренных прыжка проверяются заново. Любое расхождение даже на единицу дробного поля останавливает выполнение с указанием сценария, кадра и поля.
- В отчёт попадают только SHA-256 исходного ROM и бинарного ядра, версия ядра, числовые сводки и хеши восьми полей на каждый сценарий. Сами числовые покадровые трассы остаются в памяти процесса и не экспортируются.

## Приватный запуск

Установить ROM-free Genesis Plus GX libretro и передать инструменту пути к **локальным** файлам (не загружая их в Actions):

```sh
python3 tools/genesis_motion_repeatability.py \
  --core /private/genesis_plus_gx_libretro.so \
  --rom "/private/QuackShot Starring Donald Duck.gen" \
  --expected-sha256 30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34 \
  --repeats 2 \
  --output /private/quackshot-stage165-numeric-summary.json
```

Подозрительные или недоступные локальные файлы вызывают ошибку; отчёт не может перезаписать ROM либо ядро. Для синтетических тестов без оригинальных данных:

```sh
python3 -m unittest discover -s tests -p 'test_genesis_motion_repeatability.py' -v
```

**Статус доказательств:** прохождение GitHub Actions означает только прохождение *искусственно созданных* 16.16 фикстур. Фактическое независимое воспроизведение оригинального ROM, совпадение двух запусков на доверенной машине и синхронизация BK2 должны подтверждаться отдельно. Пока результатов приватного Stage165-запуска нет, называть трассы оригинала повторно подтверждёнными нельзя.

## Ограничения

Эта проверка не покрывает графику, звук, RAM вне восьми полей, ускорение Dash, произвольные игровые сцены, столкновения с врагами и реальное устройство Nintendo Switch. Нельзя использовать хеши полей как доказательство визуальной либо полной эмуляторной детерминированности. Измеренные константы остаются привязанными к одному SHA-256 ROM и первой городской точке входа.
