# Этап №23 — неоднозначность задержки камеры и контроль оригинальных чисел

## Проблема идентифицируемости

Предыдущий анализ сравнивал RAM-камеру 0x8524 с буфером аппаратной
прокрутки 0x852C для 0–4 прошлых кадров и ранжировал гипотезы
по суммарной пиксельной ошибке.

**Это не достаточное доказательство временной задержки.**
При скорости ровно 2 пикселя/кадр постоянно уменьшенная на 2 px
позиция может в точности совпадать с камерой предыдущего кадра,
хотя реальной временной задержки нет.

## Добавлены два независимых контрольных сравнения

В \`tools/genesis_camera_phase_model.py\` для каждого окна и каждого
кандидата считаются три группы агрегатов:

1. **Абсолютные позиции**: прежняя сумма ошибок.
2. **Изменения за кадр**: \`ΔHScroll_buffer[t] − ΔCamera[t−lag]\`.
   Они устраняют постоянный пространственный сдвиг координат.
3. **Постоянное смещение без задержки**: для каждого кандидата
   подбирается медианный pixel offset и вычисляется остаточная
   абсолютная ошибка. Отдельно сохраняется контроль нулевой
   задержки с оптимальным смещением.

Анализатор сообщает статус
\`ambiguous_spatial_offset_or_motion_signature\`, если точный
победитель по абсолютным позициям не совпадает с единственным
победителем по изменениям кадров **или** если нулевая задержка
плюс постоянное смещение объясняет данные не хуже.

Даже положительный статус
\`correlated_candidate_not_CPU_timing_proof\` не доказывает
порядок выполнения оригинального кода, VBlank или DMA:
это всего лишь совместимость end-of-frame числовых значений.

## Контроль привязки к известному оригиналу

Приватный VDP-зонд теперь дополнительно проверяет девять
заранее опубликованных числовых пар RAM 0x8524 / 0x852C
из первого городского уровня:

- RIGHT: кадры 2180, 2220, 2300, 2400;
- RIGHT→LEFT: кадры 2360, 2375, 2380, 2390, 2430.

Несовпадение хотя бы одной пары отвергает исследовательский
запуск, не позволяя объявить новую модель подтверждённой
на другом исходном состоянии эмулятора.

## Регрессии и границы

Новые синтетические тесты различают истинную задержку
при переменной скорости и ложную задержку, создаваемую
постоянным пространственным смещением. Проверяются также
повреждение и пропуск опубликованных контрольных чисел.

Ни сам ROM, ни исходные изображения, ни полные кадры RAM/VRAM
не сохраняются в репозиторий. Экспортируются только сводные
оценки и количество совпавших контрольных пар.

**Результат для оригинальной игры пока не измерен повторно:**
приватный ROM недоступен в текущем исследовательском запуске.
Камера Switch NRO сохраняет экспериментальную задержку
в один шаг; этот этап не меняет игровой движок.
