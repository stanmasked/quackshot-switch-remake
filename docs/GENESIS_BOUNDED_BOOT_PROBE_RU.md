# Этап №10 — ограниченное исполнение пролога 68000

Исходный образ: тот же приватный ROM QuackShot пользователя, закреплённый
SHA-256 30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34.
Исходный образ, фрагменты его машинного кода и графика не опубликованы.

## Реальная граница доступного исследования

В исследовательском окружении нет установленного эмулятора Sega Mega Drive
(BlastEm, MAME или RetroArch); прямой сетевой доступ для установки также
не работает. Запускать приватный ROM через публичный GitHub Actions
нельзя без передачи оригинальных байтов на внешний сервер, поэтому
от такого способа отказались.

Вместо этого tools/rom_boot_probe.py — **малый частичный интерпретатор**
68000, обрабатывающий только NOP, TST.{B,W,L} (abs.l), BRA, BEQ и BNE.
Он читает настоящий локальный ROM, но получает **синтетические**
значения аппаратных регистров, явно переданные при запуске. Вся
неизвестная инструкция или некорректный адрес останавливает проверку,
никаких неподдерживаемых машинных эффектов не моделируется.

Это проверка ветвлений **начала программы**, а не запуск игры в
полноценном эмуляторе Genesis.

## Проверенные пути от Reset PC = 0x000206

Сценарий 1: 0xA10008 = 0, 0xA1000C = 0, 0xC00004 = 0:

| Последовательность PC | Результат |
| --- | --- |
| 0x000206 → 0x00020C → 0x00020E → 0x000214 | Выполнено 4 инструкции |
| Ветвление 0x00020C | BNE не принято |
| Ветвление 0x000214 | BNE не принято |
| Следующий PC | 0x000216; неизвестная инструменту инструкция |

Сценарий 2: 0xA10008 = 1, 0xA1000C = 0, 0xC00004 = 0:

| Последовательность PC | Результат |
| --- | --- |
| 0x000206 → 0x00020C → 0x000214 → 0x000292 → 0x000300 | Выполнено 5 инструкций |
| Ветвления 0x00020C и 0x000214 | BNE приняты |
| 0x000292 | BRA → 0x000300 |
| 0x000300 | Статус VDP считан только из заглушки |
| Следующий PC | 0x000306; неизвестная инструменту инструкция |

**Внимание:** значения 0 и 1 — искусственные тестовые входы,
а не настоящие показания портов Mega Drive. Второй путь нельзя
называть наблюдением исполнения оригинальной игры на железе.

Метаданные без байтов образа:
research/observations/user_rom_bounded_boot_2026-10-17.json

## Воспроизведение локально

Из каталога репозитория:

    python3 tools/rom_boot_probe.py "/private/QuackShot Starring Donald Duck.gen" --expected-sha256 30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34 --output /tmp/quackshot-boot-zero.json

    python3 tools/rom_boot_probe.py "/private/QuackShot Starring Donald Duck.gen" --expected-sha256 30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34 --mmio-io1 0x1 --output /tmp/quackshot-boot-nonzero.json

Инструмент не посылает ROM по сети. В GitHub Actions проверяются только
синтетические, самостоятельно созданные машинные программы, отличные
от байтов оригинальной игры. Десять регрессионных тестов контролируют
ветвления, Z-флаг, ошибки адресов, остановку, предел шагов и отсутствие
машинного кода в опубликованном отчёте.

## Что потребуется для настоящей динамической трассы

Установить локальный полноценный Mega Drive эмулятор с CPU-отладчиком;
открыть предоставленный приватный ROM и подключить запись выполненных
PC/циклов, кадров VBlank, чтения 0xA10003 и изменений RAM.
Только затем можно искать реальную высоту прыжка и скорость героя.

Числовые показания нашего Switch NRO в NeXium (этап №8) пока
не сравниваются с оригиналом: они описывают временную синтетическую
механику, а не поведение оригинального QuackShot.
