# QuackShot Remake — Stage179: исправление субпиксельной границы столкновений

## Выявленный дефект

В `src/qs_game.c`, функция `hits_tiles()`, правую и нижнюю грани тела раньше вычисляли как `x + width - 0.01f` и `y + height - 0.01f`. Этот традиционный допуск исключает нулевое касание тайла, но вместе с ним игнорирует **любое реальное перекрытие меньше 0,01 пикселя**. Например, при X=388,005 и ширине героя 12px правый край заходит в тайл, начинающийся на X=400, на 0,005px. Старая проверка ошибочно считает такой ход свободным.

Это особенно важно для экспериментальной числовой модели движения с дробными 16.16-подобными координатами. Событие пересечения должно определяться по геометрической границе, а не по произвольно выбранному допуску в сотую пикселя.

## Исправление

Только для опционального режима `QS_PHYSICS_REFERENCE_CITY` в CITY TEST введены исключающие правый и нижний края:

```c
far_x = nextafterf(x + width, -INFINITY);
far_y = nextafterf(y + height, -INFINITY);
```

`nextafterf()` берёт ближайшее предыдущее **представимое значение float**. Таким образом:

- точное касание границы X=400 без положительного перекрытия остаётся разрешённым;
- любое действительно представимое положительное перекрытие с тайлом учитывается, включая доли меньше 0,01px;
- старый профиль `QS_PHYSICS_PROTOTYPE` продолжает использовать прежний допуск и сохраняет свою историческую семантику.

Эти изменения не заменяют не восстановленные пока хитбоксы оригинального QuackShot, не меняют графику и не влияют на обычный прототип.

## Регрессионная проверка

Добавлен `tests/test_reference_city_subpixel_tile.c`, всего 16 сценариев:

- 8 горизонтальных контактов со стеной: нулевой нахлёст и положительные нахлёсты от 1/4096 до 1/64 пикселя. Не допускается проникновение правого края героя внутрь тайла;
- 8 вертикальных приземлений на край тестовой платформы: при нулевом нахлёсте герой падает на нижний пол, при положительном нахлёсте фиксируется на верхней поверхности.

Тестовая карта, стенка, координаты и размеры платформы созданы самостоятельно. ROM, BK2, рисунки, звук, кадры и RAM-дампы оригинала не используются.

## Запуск

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
ctest --test-dir build -R reference_city_subpixel_tile_boundary --output-on-failure
```

Выполнение включено в обычную матрицу GCC/Clang Debug/Release. CI собирает также Nintendo Switch NRO и проверяет независимые маршруты NeXium.
