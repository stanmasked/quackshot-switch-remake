# QuackShot Remake — этап №83: постоянный индикатор воздушного сердца

Для экспериментальной сцены CITY TEST добавлена одна экранная HUD-ячейка.
Она располагается в x=389..396, y=4..11 справа от значка оружия.
Серый цвет (#5A586B) означает доступное сердце, бирюзовый (#5FE4DA)
означает получение бонуса в текущей попытке.

Индикатор намеренно не читает координаты камеры и не зависит от
16-кадрового визуального эффекта подбора. После контрольной точки и
возрождения сохраняется полученный статус; пауза не меняет его.
Новая попытка сбрасывает статус в серый.

Рендеринг запускается только при профиле QS_PHYSICS_REFERENCE_CITY
в сцене 0. Обычный прототип, остальные уровни, начисление очков,
физика, здоровье и счётчики игрового времени не изменяются.

## Регрессионная проверка

`quackshot-prototype --smoke` вызывает
`run_city_air_reward_hud_sdl_smoke()` и считывает точный
ARGB8888-пиксель (391,8) через SDL_RenderReadPixels.

Проверяются не полученное / полученное сердце, две фазы камеры,
числовое возрождение, истечение эффекта подбора, пауза, повторная
попытка и отсутствие индикатора в обычном прототипе.

Успешный коммит и запуск CI — разные факты. Пока все обязательные
задания GitHub Actions для нового SHA не завершены с результатом
success, этап не следует обозначать как полностью проверенный.
