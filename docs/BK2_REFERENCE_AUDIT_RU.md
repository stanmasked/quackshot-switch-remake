# QuackShot — исследовательский анализ BK2 (Stage161)

Этот независимый инструмент исследует **агрегаты покадрового ввода** из BizHawk BK2 для Sega Genesis / Mega Drive. Он не эмулирует игру, не выводит полный список кадров и не меняет игровую физику ремейка.

## Локальный запуск

```sh
python3 tools/bk2_reference_audit.py /private/path/Quackshot.bk2 --out /private/path/bk2_aggregate.json
python3 -m unittest discover -s tests -p test_bk2_reference_audit.py -v
```

Вывод содержит SHA-256 записи, идентификацию *по заявлению заголовка*, число кадров, счётчики удержания и новых нажатий кнопок, количество участков постоянного ввода. **Полный поток управления и ROM не публикуются.** Тесты создают только короткие искусственные BK2.

## Проверенная локально запись (сам файл остаётся вне GitHub)

- Заявленная версия: `Quack Shot Starring Donald Duck (W) (REV01) [!]`.
- BizHawk `v2.0.0`, `Genplus-gx`; автор Dooty; `rerecordCount=35026`.
- **69 608** кадров ввода, **8 368** участков постоянного ввода, **55** уникальных комбинаций кнопок первого игрока, **49** новых нажатий START.
- Второй игрок неактивен. Регионы и фактическая частота кадров **не подтверждены** воспроизведением.
- Поле `SHA1=3D79D2FCC2038B140F7481B6F64A5038` в заголовке содержит 32 шестнадцатеричных символа вместо стандартных 40 для SHA-1. Это **не** подтверждение совместимости ROM.


## Локальная проверка кандидата совместимости ROM

Если ваш исходный образ находится **локально**, без загрузки в GitHub:

```sh
python3 tools/bk2_rom_match.py /private/path/Quackshot.bk2 /private/path/Quackshot.gen --out /private/path/rom_match.json
python3 -m unittest discover -s tests -p 'test_bk2*.py' -v
```

- Если заявленный в BK2 хеш имеет **40** шестнадцатеричных символов, сравнивается SHA-1 полного локального ROM.
- Если поле называется `SHA1`, но содержит **32** символа (как у найденного BK2), отдельно сравнивается **кандидат MD5**. Это проверка гипотезы о формате старой записи, а не признание MD5 надёжной криптографической подписью.
- Если поле не соответствует этим двум форматам, результат **`unverifiable_movie_hash`**.
- `candidate_hash_match` означает только совпадение идентификатора исходных байтов ROM. Это **не** гарантия совпадения настроек BizHawk, синхронизации, контроллера или полной TAS-трассы.
- Отчёт содержит статус, длину ROM и тип алгоритма, **не содержит** сырой ROM, имени его локального пути, хеша ROM или исходных кадров. В CI используются только синтетические образцы.

**До появления доступного локального ROM** настоящий результат сравнения для исходной пользовательской записи остаётся неизвестным. Публичная ветка не должна содержать исходную запись или ROM.

## Ограничения

- BK2 сохраняет нажатия кнопок, но не координаты героя, траектории прыжков, столкновения, здоровье или видео.
- Нажатие START не обязательно означает переход между уровнями.
- Большое количество перезаписей указывает на возможное TAS-прохождение, не обязательно на обычную игру.
- Полные измерения физики потребуют локального воспроизведения оригинальной игры на проверенно совместимом ROM и ядре эмулятора.
- Синтетический `ROOFTOP TEST` из Stage160 **не** является оригинальным уровнем QuackShot. BK2 не доказывает успешность его гостевых проверок NeXium.

Следующий исследовательский шаг — частное воспроизведение записи с отдельно проверенной ревизией ROM и сохранение минимальных численных измерений, без передачи игровых ресурсов в репозиторий.
