# QuackShot Remake — Stage209: реальное приватное измерение и согласование трёх ROI

## Новые фактические данные (22 октября 2026)

В отличие от ROM-free синтетических этапов 198–208, в этой сессии
первоначальный образ **QuackShot Starring Donald Duck.gen** действительно
загружен из частного пользовательского Google Drive и запущен в локальном
инструментированном Genesis Plus GX.

Проверено до запуска:

- SHA-256 ROM: `30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34`;
- SHA-256 инструментированного ядра:
  `4e3381cf5bfa7ff387bbe6887e7e31453bf4c8c85b295aa66d6d07d415dde7aa`;
- архив исследовательского ядра получил успешный `preflight`
  Stage204 и проверку манифеста Stage203;
- оригинальный ROM остался только на локальной машине, без GitHub;
- все отчёты записаны в новые приватные JSON `0600` и прошли
  офлайн-проверку Stage208.

Был выполнен независимый режим `bracket` (Stage201): для кадров
2180, 2220, 2280, 2297, 2350 на всех четырёх сканлиниях обеих
плоскостей значения аппаратного HScroll **во время видеоколбэка** и
**после `retro_run`** совпали (все восемь целочисленных разностей
для каждого кадра равны нулю). Это **не доказывает** точную фазу
CPU/VDP/scanout или коллизию.

## Главное открытие: крупная синяя область не движется

Дополнительно проведены **три отдельных оригинальных исследования**
Stage207 с разными ROI:

| ROI (x, y, w, h) | Назначение |
|---|---|
| `100, 80, 85, 140` | Исходная широкая область |
| `115, 115, 60, 75` | Исключение нижней неподвижной полосы |
| `123, 120, 32, 60` | Самый узкий трекер цветового кандидата |

В широком ROI крупнейшая связная синяя область неизменна на всех
пяти кадрах: **1044 пикселя**, одинаковый центроид и bbox
`[100, 192, 185, 220]`. Она касается границы ROI и отсутствует
в двух меньших ROI. Считать её частью Дональда нельзя; даже
интерпретация «фон» — пока рабочая гипотеза.

Более компактная связная область одинаково воспроизводится
**во всех трёх независимых исследованиях** на каждом кадре:

| Кадр | Исходная RAM Y | Цветовая область, пиксели | Центр Y в тысячных пикселя |
|---|---:|---:|---:|
| 2180 | 176 | 131 | 131519 |
| 2220 | 176 | 106 | 129415 |
| 2280 | 176 | 116 | 131741 |
| 2297 | 208 | 138 | 166471 |
| 2350 | 208 | 131 | 163519 |

Для кадров 2280 → 2297 изменение исходной RAM Y = **32 пикселя**,
изменение центра найденной области = **34,730 пикселя**. Это
совместимо с гипотезой движения части изображения персонажа,
но не определяет исходную точку опоры или хитбокс.

Во всех трёх исследованиях совпадают числовые контрольные
состояния RAM/camera/VDP, не зависящие от выбора ROI.

## Новый ROM-free инструмент сравнения

`tools/genesis_private_cross_roi_consistency.py` принимает **только
три приватных числовых отчёта**, без оригинального ROM. Сначала
проверяется комплект SHA-pinned инструментов, затем все отчёты
отдельно проходят Stage208.

Пример для локальной машины с полным приватным архивом:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 tools/genesis_private_cross_roi_consistency.py \
  --bundle "/private/rom-free-emulator" \
  --wide "/private-results/large.json" \
  --focus "/private-results/focus.json" \
  --tight "/private-results/tight.json"
```

Инструмент проверяет вложенность ROI, точное равенство всех
независимых числовых RAM/camera/VDP значений, наличие
одного одинакового меньшего цветового кандидата на пяти
кадрах и постоянство отдельной большой краевой области
в широком ROI. Никаких пиксельных буферов не читает и не
выводит. В stdout печатает только
`GENESIS_STAGE209_PRIVATE_CROSS_ROI_NUMERIC_PASS_NOT_ORIGIN_ATTESTED`
либо общий обезличенный отказ.

Несмотря на реальные локальные прогоны, **сами сохранённые JSON
не содержат независимой криптографической аттестации процесса
эмуляции**. Поля `color_group_identified_as_original_player`,
`original_contact_plane_or_hitbox_verified` и
`safe_to_modify_switch_physics` остаются `false`.

## CI и публикация

В публичном GitHub размещаются **только** код сравнения и 11
искусственных ROM-free регрессионных тестов. Ни оригинальный
ROM, ни BK2, ни частные JSON захватов, ни кадры, ни дампы
RAM/VRAM в PR не добавляются.

Исследовательский инструмент входит в архив с проверкой
транзитивных импортов и SHA. Изменений в NRO и C99 физике нет.

**Следующий научный шаг:** независимо связать найденный цветовой
кандидат с тайлами/спрайтами персонажа, подтвердить точку опоры
и только затем оценивать изменения физики Nintendo Switch.
