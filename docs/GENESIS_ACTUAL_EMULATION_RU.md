# Этап №11 — оригинальная QuackShot в Genesis Plus GX

## Результат

**Оригинальная игра запущена в полном эмуляторе Mega Drive.**
Для этой проверки применялся только приватный пользовательский образ:
SHA-256 30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34,
512 КиБ.

Linux-ядро Genesis Plus GX libretro v1.7.4 (исходный коммит
aa74d79634cd230f65cce4180e92688e53883d2f) было собрано
в GitHub Actions **без ROM**, затем загружено в локальную среду,
где сам ROM уже находился. В GitHub не попадали ROM, его части,
оригинальные видеокадры, музыка и содержимое игровой RAM.

Собранная библиотека Genesis Plus GX имеет SHA-256:
8c0dd22e79cf9db57ce8aa0d8751592ecb6f5ba88b61432bf45a0cbd0ef68c63

Сборка без ROM:
https://github.com/stanmasked/quackshot-switch-remake/actions/runs/39062308613

Официальная лицензия Genesis Plus GX содержится рядом с архивом
библиотеки. Она включает **ограничения некоммерческого использования**.
Не включать этот сторонний эмулятор в будущий распространяемый ремейк
без проверки всех требований правообладателей.

В локально просмотренных кадрах присутствует титульный экран игры
и позднее графика игрового уровня с Дональдом. Оригинальные изображения
не опубликованы.

Скрипт действительно вызывает эмулятор: он зарегистрировал
1800 вызовов обработки ввода и 28 800 вызовов чтения состояний кнопок
в каждом сравнительном сценарии. Это в отличие от старого
tools/rom_boot_probe.py, который моделировал только несколько инструкций
68000 с искусственным I/O.

## Установленная причинность и границы достоверности

Различия между идентичными прогонами с START и без него впервые
возникают на видеоконтрольной точке 480. Это доказывает, что START
в указанном интервале меняет последовательность выводимых кадров.
Однако видеохеши сохраняются лишь раз в 60 кадров, поэтому **точный
кадр первого отличия ещё не определён**.

Проверки кнопок RIGHT, B, A и Y на более позднем участке не дали
подтверждённой разницы в видео и RAM относительно контроля. Возможные
причины — заставка, управляемая демонстрация или неправильное окно
управления. Не следует утверждать, что Дональд управляется в этих
кадрах, пока это не измерено.

Точно так же адреса RAM, которые меняются во времени, нельзя автоматически
объявлять координатами героя. **Скорость, высота прыжка, коллизии и
параметры вантуза в оригинальной игре пока не идентифицированы.**

## Как повторить локально

Ветки исследования PR №1 содержат только исходники Python и workflow
для сборки библиотеки. Из успешного запуска workflow «Genesis libretro
core (ROM-free)» скачайте артефакт «genesis-plus-gx-rom-free-linux-x64»
и распакуйте локально. Требуется Linux x86-64 с glibc и libm.

Укажите свою локальную копию ROM; никогда не добавляйте её в
отслеживаемый Git каталог:

    python3 tools/genesis_libretro_probe.py --core /private/genesis_plus_gx_libretro.so --rom "/private/QuackShot Starring Donald Duck.gen" --expected-sha256 30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34 --frames 1800 --input '450:465:START' --compare-to-idle --output /tmp/quackshot-runtime-numeric.json

Программа проверяет SHA-256 до запуска, поддерживает синхронный ввод
по кадрам, сравнивает видимые контрольные CRC32, наблюдает изменения
числа изменившихся адресов RAM и возвращает **только числовые метаданные**.
В исходном ROM не делается ни одной записи.

Если реализация libretro требует физический путь, frontend передаёт
этот путь **только локальной библиотеке**, без записи пути в отчёт.
Для тестирования GitHub Actions используется самостоятельно созданная
искусственная Sega-программа с бесконечным циклом BRA, а не оригинальная
игра. Доступны отдельные тесты парсера ввода, SHA-256 и сравнения прогона.

Публичное числовое свидетельство:
research/observations/user_rom_libretro_start_witness_2026-10-17.json

## Дальнейшая работа

1. Получить два строго сопоставимых прогона игрового уровня и выяснить,
   в какой момент управление становится доступным.
2. Сравнить покадровые изменения RAM при RIGHT/B/Y после входа в
   непосредственно управляемый этап, убирая отличия фона и анимаций.
3. Подтвердить координаты Дональда минимум двумя способами:
   изменениями RAM и независимой оценкой положения на экране.
4. Только после подтверждения скорости и прыжка менять коэффициенты
   в Nintendo Switch-движке (отдельный PR №2).

**Ни ROM, ни его ресурсы не должны попадать в облачные CI-сборки.**
