# QuackShot Remake — Stage175: удар головой о нижнюю грань потолка

## Цель

После Stage174, который проверяет приземление на верхнюю поверхность, Stage175 покрывает противоположный вертикальный контакт: герой прыгает под нависающую платформу и не должен пройти сквозь её нижнюю грань.

## Тестовая сцена

Вручную созданный потолок занимает колонки 25–32 и строки 8–9, то есть X=400..528 и Y=128..160. Пол остаётся на Y=208, герой 12×20 стартует на полу с верхом тела Y=188. Доступны четыре дробных смещения (1/4, 1/2, 3/4 и 1px) в трёх зонах: краевой нахлёст слева, центр потолка и краевой нахлёст справа.

Для каждого из 12 горизонтальных положений выполняются три длительности Jump: 1, 8 и 50 кадров — всего **36 трасс по 80 шагов**. Два независимых состояния сравниваются на каждом кадре по X/Y, скорости, grounded, HP и обеим фазам камеры.

- Короткий прыжок на 1 кадр не должен доставать до потолка.
- Прыжки с удержанием 8 и 50 кадров должны коснуться нижней грани, сбросить вертикальную скорость и затем безопасно вернуться на пол.
- Во всех сценариях верх героя не может пересечь Y=160; повторяемый контакт не должен создавать дополнительный прыжок или зависание.
- После завершения герой снова стоит на полу Y=188 с нулевой вертикальной скоростью.

## Границы вывода

Потолок и его края — искусственная тестовая геометрия, а не тайлы QuackShot. Числа удержания 1/8/50 нужны для регрессионного разделения траекторий, но только 1/50 имеют отдельные исторические измерения оригинального первого города; 8 — дополнительный тестовый режим. Результат не является новой калибровкой оригинальных хитбоксов.

В PR входят только C-тест, запись в CMake и эта документация. Игровой код и стандартная сцена не меняются; оригинальный ROM, BK2, кадры, звук и дампы памяти не добавляются.

## Запуск

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
ctest --test-dir build -R reference_city_head_bump --output-on-failure
```
