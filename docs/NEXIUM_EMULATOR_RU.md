# QuackShot — воспроизводимый запуск NRO в эмуляторе NeXium

Дата первого подтверждённого запуска: **17 октября 2026**.
Проверялся исключительно наш технический NRO, без оригинального
образа Mega Drive, Disney/Sega-ресурсов, системных ключей Nintendo
или коммерческой прошивки.

## Что действительно проверено

Среда: GitHub Actions, Ubuntu 26.04 (glibc 2.43), Xvfb,
Mesa Vulkan 1.4 / llvmpipe (программный рендерер), NeXium nightly.

Бинарный файл NeXium перед запуском проверяется по SHA-256:
29250067b941f84b85a4fc2ec1357eeba33b31334b715c3b33545c38146eed76

Наш NRO из текущей ветки собирается повторно непосредственно в CI;
ранее проверенный исполняемый файл имел SHA-256:
d600537d7905a9e6c18f2856637c43f79cff9f87f314f6e0b5c58f81c3985fb9

Работоспособность установлена **не только по логам NeXium**, но и по
числовому журналу, который создал исполняемый NRO внутри эмулятора:

1. BOOT → SDL_READY → WINDOW_READY → RENDERER_READY.
2. CONTROLLER (обнаружен эмулируемый игровой контроллер).
3. FIRST_FRAME (реальный вызов SDL_RenderPresent из гостевого приложения).
4. HEARTBEAT после 600, 1200 и последующих кадров.
5. STAGE_CHANGE в игровую сцену после виртуального нажатия кнопки A.
6. STAGE_CHANGE обратно на карту после виртуального нажатия Plus.

В подтверждённом тесте клавиатурного ввода переход на игровую сцену
произошёл на **кадре 187**, возврат на карту — **на кадре 517**.
Приложение продолжало исполнение после обоих переходов.

## GitHub Actions и доказательства

- Первый запуск с доказанным выводом кадров и 4200 шагами симуляции:
  https://github.com/stanmasked/quackshot-switch-remake/actions/runs/39055102817
- Первый запуск, подтвердивший управление A/Plus через NeXium:
  https://github.com/stanmasked/quackshot-switch-remake/actions/runs/39055577000
- Автоматизирующие скрипт и workflow:
  tools/nexium_ci_probe.sh
  .github/workflows/emulator-runtime.yml

Последняя версия CI **требует** не только FIRST_FRAME, но и:
- два перехода STAGE_CHANGE (карта → сцена → карта);
- подтверждённый подключённый контроллер;
- не менее 600 шагов и запись HEARTBEAT.

Если хотя бы одно условие не наблюдалось, CI не объявляет тест успешным.

### Почему процесс завершается кодом 137

Запуск намеренно ограничен по времени через timeout и изолирован в
тестовом окружении GitHub. Сообщение об окончании по тайм-ауту само
по себе **не является ошибкой эмулятора или игры**; однако тест не
проверяет корректное закрытие окна из главного меню.
Успех определяется исключительно гостевым журналом.

### Ограничения

- Запуск на настоящей Nintendo Switch и Joy-Con не проверены.
- Звук на беззвучном CI runner не проверен: NeXium отключает аудиовывод.
- Проверены A и Plus; физика движения, B/прыжок и Y/выстрел
  требуют отдельных игровых свидетельств.
- 3 полигона, примитивная графика и константы движения — временные.
  До точного ремейка оригинальной QuackShot ещё далеко.
