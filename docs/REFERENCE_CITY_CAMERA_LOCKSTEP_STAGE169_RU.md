# QuackShot — Stage169: независимый контроль движения камеры CITY TEST

## Что проверяем

В opt-in профиле `QS_PHYSICS_REFERENCE_CITY` камера используется как **синтетическая модель**, созданная на основании числовых наблюдений оригинальной игры. В приватно исследованном первом городском участке поле RAM `0x8524` коррелирует с прокруткой: при слежении вправо разница мировой X и кандидата прокрутки лежит в **[140, 142]**, влево — в **[122, 124]**. Для прототипа выбраны центры диапазонов **141 и 123** пикселя.

Тест `tests/test_reference_city_camera_lockstep.c` фиксирует **240 последовательных шагов** на ровной оригинально-независимой тестовой плоскости. Он не пользуется логикой вычисления камеры из игрового `qs_game.c`: собственной целочисленной моделью **16.16** рассчитывает скорость, мировую X, моменты входа в горизонтальную deadzone и положение игровой камеры.

Каждый кадр проверяются:
- позиция и скорость героя против отдельного целочисленного расчёта;
- начало и окончание слежения камеры вправо/влево по порогам 141/123;
- полоса гистерезиса между порогами при развороте и отпускании ввода;
- задержка изображения `render_camera_x` на один шаг от `camera_x`;
- повторяемость всех величин при двух независимых стартовых состояниях.

Сценарий: 120 шагов вправо, 35 влево, 25 без направления, 60 вновь вправо. Коллизии, предметы, противники и платформа выше земли выключены **только в тестовой фикстуре**. Нельзя выводить точную геометрию оригинала по результату этого теста.

## Запуск

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
ctest --test-dir build -R reference_city_camera_lockstep --output-on-failure
```

Запуск включён в стандартный CI переносимого игрового ядра (GCC/Clang, Debug/Release). Не требуется ROM, снимок экрана, BK2, пользовательский savestate или копия оригинальных тайлов.

## Границы достоверности

- RAM `0x8524` — **кандидат** на прокрутку в конкретном оригинальном состоянии. Это не доказанная декодировка регистра VDP.
- Пороги 123/141 и задержка рендеринга на один кадр — явные предположения нашей новой модели, основанные на опубликованных измерениях, не извлечённый оригинальный алгоритм.
- Координаты Switch-прототипа и 400px viewport не совпадают с исходной картой Mega Drive.
- Результат `PASS` доказывает стабильность **нашей** реализации относительно независимо рассчитанной модели; точность по оригинальному ROM должна устанавливаться отдельными эмпирическими испытаниями.
