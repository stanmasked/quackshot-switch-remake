# QuackShot Remake — этап №79: бюджет личного рекорда второго сектора

## Новое игровое отображение

После успешного прохождения CITY TEST с контрольной точкой появляется
личный рекорд **второй половины уровня** (этап №78). Теперь при новом
заходе за флажок игрок сразу видит **оставшееся число кадров до этого
рекорда**. Под сиреневыми цифрами второго таймера расположен небольшой
горизонтальный индикатор из самостоятельно нарисованных пикселей.

- **Зелёная полоска:** текущий второй сектор ещё короче рекорда.
  Полоска постепенно уменьшается, пропорционально остающемуся
  количеству кадров.
- **Голубая полоска:** время ровно сравнялось с рекордом.
  Ноль — полноценное сравнение, а не отсутствие результата.
- **Красная полоска:** рекордное время превышено. Это не
  блокирует выход и не штрафует игрока.
- **Нет полоски:** ещё не был заработан ни один завершённый
  второй сектор либо флажок в текущей попытке не достигнут.

Никаких промежуточных результатов для сравнения не выдумывается:
при отсутствии проверенного результата предыдущего финиша полоска
не отображается.

## Правила и архитектура

Два новых API игрового ядра:

- `qs_city_sector_budget_valid()` — есть ли у текущей попытки
  безопасные данные для сравнения с реально завершённым вторым
  сектором;
- `qs_city_sector_budget_frames()` — подписанная величина
  `личный_рекорд_сектора - текущее_время_сектора`.

Эта величина вычисляется из существующих таймеров и не требует
нового сохраняемого поля. При активной паузе X + Start она не
меняется; смерть и появление у контрольной точки не восстанавливают
бюджет. R + Start очищает текущий индикатор, сохраняя лучший
результат сессии. После финиша или выхода на карту живой бюджет
не показывается.

Все значения проверяются в пределах 1–9999 кадров до вычитания.
Неверные, отсутствующие или неподходящие для основного профиля
данные не могут активировать полоску. Математика отрисовки
использует безопасное целочисленное масштабирование до ширины
29 пикселей; она не зависит от аппаратной частоты кадров.

## Проверки

`tests/test_reference_city_sector_budget.c` — **16 сценариев**
и **480-кадровый детерминированный прогон**. Проверяются отсутствие
предыдущего рекорда, достижение флажка, уменьшение остатка,
ничья, превышение рекорда, пауза, гибель, Back, R + Start,
настоящий финиш, повреждённые значения и режим обычного
прототипа.

SDL2-проверка `CITY_SECTOR_BUDGET_SDL_PASS` считывает реальные
ARGB8888-пиксели полоски:

- зелёная полная полоска при бюджете 6 кадров;
- укороченная полоска шириной 15 пикселей при бюджете 3;
- голубая при бюджете 0;
- красная при бюджете −1;
- отсутствие полоски при первой попытке, быстром перезапуске
  и в обычном профиле;
- неизменность изображения в течение 15 замороженных кадров.

Тест добавлен в обязательные маркеры SDL2 CI, CTest выполняется
для GCC/Clang, а Switch NRO и NeXium проверяются отдельно.

Это самостоятельно созданный интерфейс тестового CITY TEST,
не реконструкция оригинальной механики QuackShot и не её игровые
ресурсы. ROM и другая оригинальная интеллектуальная
собственность не публикуются.
