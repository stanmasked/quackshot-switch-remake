# NeXium — повторное закрепление nightly от 20 октября 2026 года

## Причина

В PR №3 (новая игровая плита RUINS TEST) первые два запуска
NeXium ([CI №39391510052](https://github.com/stanmasked/quackshot-switch-remake/actions/runs/39391510052))
завершились **до запуска эмулятора**: `sha256sum -c` не принял
прошлую сумму от 18 октября. Артефакты CI `result.txt`
содержат `BLOCKED: NeXium nightly hash differs from pinned SHA-256`,
а `download.log` подтвердил получение полного архива ~108,8 MiB.

CI правильно отказался исполнять изменившийся бинарный файл.
Игровая симуляция здесь не выполнялась, поэтому этот результат
не доказывает неисправность механики RUINS TEST.

## Ручная проверка официальной публикации

Дважды запрошен GitHub Releases API официального репозитория:

https://api.github.com/repos/nexium-emu/nexium-nightly/releases/tags/nightly

- Release tag: `nightly`.
- Название: `NeXium nightly 2026.10.20 (0895625)`.
- Release id: `340509243`.
- Archive: [nexium-linux-x86_64.tar.gz](https://github.com/nexium-emu/nexium-nightly/releases/download/nightly/nexium-linux-x86_64.tar.gz).
- Asset id: `658656899`.
- Размер: `114182978` байт.
- Последнее изменение: `2026-10-20T07:55:02Z`.
- Опубликованный `digest`:
  `sha256:c933fbbcf8d1b011de8d4a79c9d8eb55c0678a305947af9388ddb40ce5960a66`.

В CI закреплена только точная шестнадцатеричная часть SHA-256:
`c933fbbcf8d1b011de8d4a79c9d8eb55c0678a305947af9388ddb40ce5960a66`.

**Проверка `sha256sum -c` перед распаковкой и запуском эмулятора
сохранена без ослаблений.** Если nightly вновь изменится, этот CI
снова должен прекратить работу, а не автоматически одобрить архив.

Сопоставление опубликованного GitHub digest с скачанными байтами
подтверждает принадлежность к конкретному release asset.
Это **не** означает аудит безопасности содержимого эмулятора,
не подтверждает его поведение и не заменяет запуск NeXium.
После обновления pin все пять игровых прохождений, нативные CTests
и итоговые сравнения должны быть повторно выполнены на новом SHA.

Предыдущая [запись от 18 октября](NEXIUM_PIN_2026_10_18_RU.md)
остаётся историческим журналом, но больше не является актуальным pin.
