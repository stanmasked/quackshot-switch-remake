# QuackShot Remake — этап №152: отрицательный тест касания ROOFTOP

Следующий автономный этап после [подтверждённого в NeXium моста](https://github.com/stanmasked/quackshot-switch-remake/tree/milestone/stage151-rooftop-guest-verified).

## Зачем

Мост должен появляться **только после попадания жёлтого снаряда**.
Касание переключателя героем — недостаточное условие. Старые
C99-тесты уже проверяли это отдельно; теперь нужна реальная проверка
в Nintendo Switch NRO в эмуляторе NeXium.

## Новый гостевой маршрут

Две независимые сессии запускают **ту же оригинальную ROM-free NRO**.
Управление NeXium осуществляется настоящими виртуальными кнопками:

1. Два D-pad Down, затем Nintendo A выбирают ROOFTOP TEST.
2. R+Right приводит героя к x~630; обычный Right плавно подводит
   его к x~695–710, где собственный прямоугольник героя пересекает
   область переключателя x704..716.
3. **FIRE не нажимается ни разу.** После остановки герой
   некоторое время стоит на земле вплотную к переключателю.
4. Проверяется NRO-созданный CSV: все кадры последовательны,
   команда FIRE отсутствует, ни одного живого снаряда нет,
   все шесть клеток моста по-прежнему нетвёрдые.
5. После наблюдения отправляется настоящая кнопка START для выхода
   на карту, чтобы не спутать этот тест с поздним контактом врага.
6. Итоговое сравнение подтверждает разные профили, одинаковые байты
   NRO, опубликованную SHA эмулятора и сопоставимый момент касания.

## Границы проверки

Этот этап **не** проверяет красный снаряд и восстановление моста
при повторном входе. Эти два отрицательных сценария требуют
своих настоящих маршрутов с дополнительными этапами меню и
останутся отдельными задачами. Положительный сценарий №151
и его контрольная ветка не изменяются.

Никакие игровые исходники, защищённые ресурсы, ROM, коллизии,
критерии таймингов CITY TEST и старые проверки не ослабляются.
До успешного NeXium CI нельзя заявлять о подтверждённом
отрицательном сценарии.
