# Этап №13 — первая измеренная физика оригинальной QuackShot

17 октября 2026. Источник: пользовательский 512-КиБ ROM с SHA-256
30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34.

Оригинальный ROM, игровые изображения, музыка и сырые дампы RAM не
отправлялись в GitHub. Исследование выполнено приватно в
Genesis Plus GX libretro v1.7.4.

## Как получен реальный управляемый уровень

В предыдущих опытах наблюдалась автоматическая демонстрация, а не
управление. Новый ввод проходит оригинальное меню по кадрам:

1. START 450–461: титульный экран.
2. START 680–691: меню «СТАРТ / ОПЦИИ».
3. START 850–861: подтверждение «СТАРТ».
4. START, по 5 кадров с начала 1100, 1145, 1190, 1235, 1280, 1325,
   1370: пропуск вступления, получение городской локации.
5. Больше START не нажимаем: Дональд стоит перед входной дверью.

На кадре 2070 подаётся ровно одно игровое действие.
Все независимые прогоны воспроизводят одинаковую предысторию,
а два бездействующих контроля совпадают по данным RAM и видео CRC32.

Первые изменившиеся видеокадры: RIGHT — 2072, Mega Drive B — 2072,
Mega Drive A — 2071. Локальная визуальная проверка подтверждает:
RIGHT = движение; A = прыжок; B = жёлтый вантуз. Это уже реальные
действия игрока, а не демонстрационный сценарий.

## Карта игрового состояния в 64 КиБ RAM

| Смещение | Интерпретация |
|---|---|
| 0xA2D0 | Координата X персонажа в игровом мире |
| 0xA2D4 | Координата Y персонажа в игровом мире |
| 0x8F58 | Кандидат на экранную X |
| 0x8F54 | Кандидат на экранную Y |
| 0xA2D8 | Целочисленная часть горизонтальной скорости, кандидат |
| 0xA2DC | Целочисленная часть вертикальной скорости, кандидат |
| 0x9C00 | Активность слота снаряда/вантуза |

Координаты читаются 16-битными little-endian словами в структуре
игровой памяти. Это формат **конкретных игровых данных**, а не
утверждение о порядке байтов процессора Motorola 68000.

## Подтверждённые числовые наблюдения

| Параметр | Значение |
|---|---|
| Исходные X, Y | 61, 176 пикселей мира |
| Вправо: X на кадрах 2090 / 2160 | 87 / 201 |
| Установившаяся скорость вправо (114 / 70) | 1,628571 пикселя/кадр |
| Левая координатная граница | 16 |
| Начальная Y / Y в вершине | 176 / 111 |
| Подъём прыжка | 65 пикселей |
| Кадр вершины | 2097 |
| Кадр приземления | 2126 |
| Длительность прыжка | 56 кадров |
| Первый активный слот вантуза после B | кадр 2071 |
| Фактически обработано нажатий RIGHT/LEFT/A/B | 120 / 120 / 50 / 50 |

Наблюдения получены при одинаковом старте, по независимым сценариям.
Скорость установлена по разности *мировых координат*, а не по
приблизительному смещению спрайта в кадре. Дробные поля внутреннего
формата скорости (включая A2DA/A2DE) ещё требуют анализа.

## Воспроизведение с локальным приватным ROM

Используйте ROM-free Genesis Plus GX из GitHub Actions и оригинальный
ROM только на собственной машине. Из корня PR №1 запустите:

    python3 tools/genesis_playable_physics.py \
      --core /private/genesis_plus_gx_libretro.so \
      --rom "/private/QuackShot Starring Donald Duck.gen" \
      --expected-sha256 30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34 \
      --output /tmp/quackshot-playable-physics.json

Инструмент воспроизводит 6 сценариев по 2320 кадров, проверяет
совпадение двух контрольных прогонов, получение реальных кнопок
libretro, направление движения, дугу прыжка и активность вантуза.
В диапазоне 2069–2220 он читает RAM на каждом кадре, но сохраняет
только выбранные числовые параметры и агрегаты.

Числовой результат опубликован отдельно:
research/observations/user_rom_first_playable_physics_2026-10-17.json

GitHub Actions не получает ROM: используется самостоятельно написанная
синтетическая программа Mega Drive, а регрессионные тесты применяют
искусственные данные.

## Ограничения точности и следующий этап

Измерен один открытый участок городского уровня, не все локации.
Для полного ремейка необходимо проверить ускорение на других
поверхностях, дробные скорости, столкновения и режимы оружия.
Не переносить напрямую значения в Switch-движок, пока не выровнены
масштаб и системы координат игровых карт.

Switch NRO уже запускается в NeXium, но физическая консоль
Nintendo Switch пока не тестировалась.
