# QuackShot Remake — Stage207: защищённый запуск числовых кандидатов цвета

## Задача

Stage205 позволяет находить связные цветовые области в приватных
видеокадрах оригинального Genesis, но прямой запуск Stage200 обходил
единую проверенную точку входа Stage204. Stage207 делает анализ
доступным через **тот же проверяемый приватный комплект**, который
сначала подтверждает хеши файлов и исторического ядра.

## Новый параметр

На совместимом Linux x86-64 с собственным локальным оригинальным ROM:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 tools/genesis_private_bundle_launcher.py \
  --run --mode triplet --component-candidates \
  --rom "/private/QuackShot Starring Donald Duck.gen" \
  --output "/private-output/quackshot-color-groups.json"
```

Указанные выше пути — лишь пример. ROM остаётся вне репозитория
и вне исследовательского комплекта. Это программа для **локального
использования**, не задача для публичного GitHub Actions.

Запускатель проверяет SHA-256 всего ROM-free комплекта и
инструментированного Genesis Plus GX до открытия игры. После
проверки SHA оригинального ROM три независимых запуска сверяют
числовые результаты idle, RIGHT и повторного RIGHT.

Отчёт состоит только из числовых контрольных позиций RAM, аппаратного
VDP HScroll, статистики цветных областей и ограниченных по количеству
прямоугольников. Исходные RGB-буферы, сырая RAM и VRAM
**не записываются**. Отчёт помещается исключительно в новый
приватный файл вне Git с правами `0600`.

## Ограничения

`--component-candidates` разрешён **только** при
`--run --mode triplet`:

- В `--preflight` флаг запрещён: проверка среды не должна
  делать вид, что исходные цвета были измерены.
- В `--mode bracket` флаг запрещён: Stage201 измеряет временную
  разницу аппаратного HScroll и не предоставляет подтверждённой
  схемы цветовых компонент.
- При отсутствии флага старые интерфейсы Stage204 сохраняются.
  Появление новых цветовых полей в режиме без флага считается
  нарушением контракта.
- При включении флага проверяется точный набор полей каждого
  компонента, целочисленные границы и согласованность количества
  синих пикселей со старым детектором на пяти кадрах.
- Любые дополнительные поля с сырыми пикселями, изменённая
  последовательность кадров или ложное утверждение, что найден
  именно спрайт Дональда либо коллизионная граница, вызывают отказ
  **до записи файла**.

В консоли выводится только обезличенный PASS/REJECTED.
Оригинальные пути и числовые свидетельства не печатаются.

## ROM-free тесты

Девять тестов `tests/test_genesis_private_color_launcher.py`
проверяют корректность опционального режима, запрет остальных
режимов, подделку кадров и структуры JSON, отсутствие публикации
сырых байтов и передачу флага в реальный алгоритм Stage200.
В GitHub Actions используются только искусственные данные.

Stage207 не меняет игровую физику, graphics pipeline или
Nintendo Switch NRO. Даже большой единый синий компонент
**не доказывает**, что найдено тело, опора ног или исходный хитбокс.
До отдельного оригинального эксперимента
`safe_to_modify_switch_physics=false`.
