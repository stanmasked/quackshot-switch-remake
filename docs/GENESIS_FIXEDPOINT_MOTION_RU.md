# QuackShot — этап №15: покадровая физика оригинала, формат 16.16

## Подтверждённые наблюдения

Источник — **только приватная эмуляция** пользовательского QuackShot ROM
(512 КиБ), SHA-256:
30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34.

Genesis Plus GX libretro v1.7.4, исходный коммит
aa74d79634cd230f65cce4180e92688e53883d2f.

Никакие ROM-байты, видео, музыка, спрайты или RAM-дампы не загружены
в GitHub. Опубликованы только значения физических параметров,
отметки кадров и хеши источника.

Для входа в первый управляемый городской уровень используется
уже подтверждённая последовательность START. С кадра 2070
отдельно проверены семь сеансов: без ввода, повтор контроля, RIGHT
100 кадров, RIGHT 8 кадров, LEFT 100 кадров, A 1 кадр, A 50 кадров.

Исследовательский инструмент tools/genesis_fixedpoint_motion.py
выполняет эти сеансы и сравнивает числовую RAM-трассу **каждый кадр
в окне 2069–2190**. До первого нажатия результаты обязаны совпадать.

## Точное представление чисел

В исследуемой структуре оперативной памяти координаты и скорости
состоят из **16-битного знакового целого слова** и **16-битной
беззнаковой дробной части**, читаемых отдельно в порядке младшего
байта первым. Число:

    integer + fraction / 65536

Например, скорость +1 и дробь 0xA000 равна 1,625.
Скорость −3 с дробью 0x1200 равна −2,9296875.

Это описание полей игровой структуры в RAM, **не** утверждение,
что процессор Motorola 68000 является little-endian.

Смещения внутри 64 КиБ RAM:

| Смещение | Поле |
|---|---|
| 0xA2D0 | Целая часть мировой X |
| 0xA2D2 | Дробная часть мировой X |
| 0xA2D4 | Целая часть мировой Y |
| 0xA2D6 | Дробная часть мировой Y |
| 0xA2D8 | Целая часть скорости X |
| 0xA2DA | Дробная часть скорости X |
| 0xA2DC | Целая часть скорости Y |
| 0xA2DE | Дробная часть скорости Y |

## Горизонтальное движение

| Измерение | Результат |
|---|---|
| Изменение скорости за один кадр | 0x2800 / 65536 = **0,15625** |
| Предел ходьбы | 0x1A000 / 65536 = **1,625 пикс./кадр** |
| Кадр первого достижения предела | **2080** (11-й шаг) |
| Торможение при отпускании RIGHT | **0,15625** за кадр |
| RIGHT 8 кадров | скорость достигает **1,25** |
| Спустя ещё 8 кадров после отпускания | скорость **0**, X изменился с 61 до **71** |
| Координата X на кадре 2090 | **87** (субпиксели 0,46875) |
| Координата X на кадре 2160 | **201** (субпиксели 0,21875) |

Это позволяет вычислить ускорение и торможение без подгонки
экспоненты по двум наблюдениям. Наблюдавшийся прирост координаты
за 21 шаг равен **26,46875**, а за 91 шаг — **140,21875**.

Движение влево имеет соответствующий отрицательный прирост скорости
до **−1,625**, но около левой стены мировая координата ограничена 16.
Это не означает, что и на остальных картах граница всегда равна 16.

## Управление высотой прыжка

Наблюдаемая начальная вертикальная скорость составляет
**−2,9296875 пикселя/кадр**. При отпускании кнопки A вертикальная
скорость возрастает на **0,1953125** каждый кадр. Когда A
удерживается, вертикальная скорость остаётся постоянной до 15 шагов;
после пятнадцатого шага начинается то же изменение на 0,1953125.

| Сценарий | Высота | Первая вершина | Приземление |
|---|---:|---:|---:|
| A нажата 1 кадр | **24 пикс.** | 2083 | 2100 |
| A удерживается 50 кадров | **65 пикс.** | 2097 | 2126 |

Иными словами, при нажатии с кадра 2070 короткий прыжок возвращается
на землю **через 30 кадров**, а длительный — **через 56 кадров**.

У длительного прыжка движение пересекает опорную высоту перед
кадром 2126, а коррекция контакта происходит на следующем кадре.
Это отдельная особенность столкновения в оригинале, которую нельзя
смешивать с вычисленной гравитацией.

## Воспроизведение приватно

Из исследовательской ветки PR №1, с установленным ROM-free
Genesis Plus GX из проверенного GitHub Actions:

    python3 tools/genesis_fixedpoint_motion.py \
      --core /private/genesis_plus_gx_libretro.so \
      --rom "/private/QuackShot Starring Donald Duck.gen" \
      --expected-sha256 30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34 \
      --output /tmp/quackshot-fixedpoint-motion.json

Инструмент прерывает проверку при изменении контрольного сеанса,
отсутствующих кадрах, неправильном количестве событий ввода,
неправильной скорости, координатах или отличающейся дуге прыжка.

Готовые числа и SHA-256 публично зафиксированы в
research/observations/user_rom_fixedpoint_motion_2026-10-18.json.

Для CI используются исключительно искусственно созданные числовые
фикстуры и самостоятельный синтетический ROM без игровых данных.

## Значение для Nintendo Switch-ремейка

Модель референсного города в отдельном PR №2 теперь может использовать
**измеренные** ускорение, торможение и управление высотой прыжка вместо
аппроксимирующей экспоненты и постоянного прыжкового параболоида.

Тем не менее точная эквивалентность не доказана для движения у стен,
под платформами, на других уровнях, в состоянии урона или ускорения.
Геометрия тестовых сцен Switch пока полностью искусственная.
Перенос допустим только в отдельно включаемом исследовательском профиле.
