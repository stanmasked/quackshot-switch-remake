# Этап №8 — доказательства движения и оружия в NeXium

## Назначение

Теперь приложение создает **два независимых числовых журнала**:

- quackshot-runtime.csv — загрузка, первый кадр, контроллер и смена сцены;
- quackshot-motion.csv — полученный гостевым кодом ввод и состояние
  героя, снарядов и оглушённых противников.

Значения вычисляются внутри нашего 64-битного ARM-приложения,
которое NeXium исполняет как Nintendo Switch homebrew.
Сторонний скрипт **не подставляет** числовые данные о движении:
он только отправляет клавиши, читает гостевой CSV и анализирует его.

На Switch второй файл создаётся по пути:

    sdmc:/switch/quackshot-motion.csv

При ошибке записи приложение продолжает работать. Оба CSV
перезаписываются при следующем запуске. Журнал движения ограничен
256 строками, во избежание бесконтрольного износа и переполнения SD.
Запись производится раз в пять шагов симуляции, а также в кадрах
изменения кнопок и при входе в сцену. Каждая строка сбрасывается
в файл отдельно. После 256 записей сбор данных о движении прекращается.

## Поля числового журнала

| Поле | Значение |
|---|---|
| seq | Номер записи в текущей сессии |
| frame | Глобальный номер 60-Гц шага игрового движка |
| ticks_ms | Миллисекунды SDL2, НЕ такт оригинальной Mega Drive |
| stage | Синтетический тестовый полигон (0–2) |
| input_bits | Маска полученных кнопок |
| x_milli, y_milli | Координаты тестового героя ×1000 |
| vy_milli | Вертикальная скорость ×1000 |
| grounded | Признак контакта с землёй |
| active_shots | Число активных тестовых снарядов |
| attached_shots | Число закреплённых красных вантузов |
| stunned_enemies | Количество оглушённых противников |

Маска input_bits: 1=лево, 2=право, 4=прыжок (B), 8=огонь (Y),
16=ускорение (R), 32=выбор/вход (A), 64=возврат (Plus).

## Как работает интеграционная проверка

Эмулятор NeXium загружается из проверенного по SHA-256 архива,
после чего GitHub Actions выполняет именно собранный NRO
в программной среде Vulkan/Mesa.

Сценарий ввода: A → B (прыжок на открытом участке) → вправо → Y → Plus.
Проверка требует наличие следующих наблюдаемых фактов:

1. Настоящий первый кадр и два перехода карта → сцена → карта.
2. В гостевом журнале input_bits содержатся право, B и Y.
3. Изменение X больше 15 тестовых пикселей.
4. Изменение Y вверх больше 12 тестовых пикселей.
5. В хотя бы одной записи active_shots > 0.
6. Последовательность кадров/строк корректна, запись ограничена.

В ходе первых интеграционных прогонов обнаружено и исправлено различие
физического расположения кнопок Nintendo и Xbox-нормализации SDL2:
на Switch B → SDL A, A → SDL B, Y → SDL X, X → SDL Y.
Десктопная раскладка осталась прежней.

Это проверки **текущего синтетического движка**, а не измерения
поведения оригинального QuackShot.

## Что ещё нельзя утверждать

- Скорость ходьбы 1.9, скорость ускорения 3.1 и начальная скорость
  прыжка −7.2 — временные коэффициенты в src/qs_game.c.
- Координаты и враги не извлечены из оригинальной QuackShot.
- Даже успешная проверка NeXium не доказывает соответствие движка
  оригинальной Mega Drive и не заменяет испытание Nintendo Switch.

Для сопоставления с оригиналом потребуется измеренная кадровая трасса
**пользовательского образа**, идентифицированного по SHA-256
30581220f6c914709853828811fe143e283896189a64eedf1444dc908b5cac34.
Сами ROM-байты ни в журнал, ни в GitHub не помещаются.

Результаты очередного NeXium-прогона сохраняются как
nexium-emulation-evidence: guest-motion.csv, motion-summary.txt,
guest-runtime.csv, result.txt и журналы эмулятора.


## Подтверждённый результат NeXium — 17 октября 2026

GitHub Actions: https://github.com/stanmasked/quackshot-switch-remake/actions/runs/39056856676

Строгая проверка завершилась успешно. Вход на полигон зафиксирован
на шаге 234, возврат на карту — на шаге 605. После выхода NRO
продолжил выполнять игровую симуляцию до 2400-го шага.

Гостевой числовой журнал (80 записей) подтвердил:
- Получение команды вправо и смещение по X **117,799 пикселя**.
- Получение кнопки B и подъём героя на **76,801 пикселя**.
- Получение кнопки Y, появление **1 активного вантуза**.
- Правильный порядок и ограниченное число записей.

Для воспроизводимости сохранён итоговый числовой манифест:
