# QuackShot Remake — Stage197: проверка внешнего числового контакта без ложной аттестации

## Чего не хватает после Stage194–196

Значения Y=176 и Y=208 в исходных исследованиях QuackShot — это
**состояния игрока в рабочей RAM Genesis**, а не самостоятельно
измеренные вертикальные положения плоскостей столкновения. Две
координаты дают перепад 32px, но по ним невозможно узнать ни размеры
исходного хитбокса, ни вертикальную точку привязки.

Stage197 добавляет не новую «измеренную» геометрию, а строгий контракт
проверки **возможных будущих приватных числовых измерений** поверхности.
Ни один оригинальный ROM не запускается этим этапом.

## Условия числового свидетельства

Входной JSON `quackshot_private_genesis_contact_planes_numeric_v1`
должен иметь ровно четыре записи:

- `upper` — два независимых повтора для верхней опоры;
- `lower` — два независимых повтора для нижней опоры.

Каждая запись содержит только `site`, `repeat`,
`player_ram_y_q16` и `independent_contact_plane_y_q16`.

Высоты плоскостей **должны быть получены независимо от координаты
героя RAM**: например, в отдельном эксперименте по поиску границы
столкновения. Перенос в поле `independent_contact_plane_y_q16`
значений 176 и 208 из старого отчёта не является независимым измерением.

Проверяется:

1. Согласованность с закреплёнными хешами исходного ROM и бинарника GX.
2. Фаза выборки RAM `post_retro_run_before_next_input`.
3. Точный формат JSON без дополнительных полей, кадров/RAW RAM/изображений.
4. Два повтора на каждом уровне, отсутствие дубликатов.
5. Одинаковая кандидатная разница `plane_y - player_ram_y` во всех
   четырёх пробах при стабильных плоскостях контакта.
6. Сохранение интервала 32px между двумя поверхностями.

Результат с такими данными всегда получает статус
`EXTERNAL_CONTACT_NUMBERS_NOT_INDEPENDENTLY_ATTESTED`. Формальная
согласованность четырёх чисел **не подтверждает истинность эксперимента**.
Поля `original_anchor_independently_attested`,
`original_hitbox_size_verified` и
`safe_to_modify_switch_physics` остаются `false`.

Без входного файла результат имеет статус
`ORIGINAL_COLLISION_SURFACES_NOT_MEASURED` и `null` вместо
вычисленного смещения.

## Работа в изолированной директории

Без приватных измерений:

```sh
python3 tools/city_original_contact_candidate.py
```

Когда независимые **числовые** данные действительно будут получены:

```sh
python3 tools/city_original_contact_candidate.py \
  --numeric-witness "$HOME/private-quackshot/contact-planes-numeric.json" \
  --out "$HOME/private-quackshot/contact-candidate-report.json"
```

Второй режим требует абсолютный путь **за пределами репозитория** и
новое имя выходного файла. Отчёт сохраняется с правами `0600`
атомарно и не выводится в stdout. Существующий отчёт не
перезаписывается. Приватные пути не включаются в ошибки.

## Искусственные ROM-free проверки

`tests/test_city_original_contact_candidate.py` использует
**исключительно выдуманные** контактные плоскости для проверки
алгоритма. Синтетическая гипотеза со смещением +20px — лишь тест
арифметики, а не наблюдение оригинального QuackShot.

CI проверяет отсутствие свидетельства, точный JSON-контракт,
посторонние поля, дубликаты, несовпадающие повторения, ложные хеши,
подмену фазы выборки, противоречивые плоскости, права приватного вывода
и запрет перезаписи.

В Stage197 не изменяются физика C99, управление, собственная
геометрия CITY TEST, графика или Switch NRO; ни один оригинальный
ROM, BK2, RAW RAM, скриншот, видео или аудиофайл не добавляются в git.
