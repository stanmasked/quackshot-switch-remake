# Этап №40 — одновременные попадания в совмещённые поверхности врагов

В экспериментальном CITY TEST при столкновении снаряда с двумя
перекрывающимися врагами раньше выбирался только первый
попавшийся слот массива. При одинаковой координате ближайшей
поверхности врагов это означало произвольную зависимость
от порядка хранения актёров.

Теперь при попадании снаряда обе цели с одинаковой
ближайшей поверхностью (точное совпадение с допуском
0,0001 пикселя для ошибок представления float) оглушаются.
При этом:
- снаряд по-прежнему поглощается при попадании;
- враг за более далёкой поверхностью не оглушается;
- враг вне вертикального хитбокса не оглушается;
- настоящая твёрдая стена имеет приоритет при равной
  ближайшей поверхности и блокирует оба попадания;
- для обычного профиля старый приоритет слота сохранён;
- положительные счётчики оглушения уменьшаются один раз
  в том же кадре, как было раньше.

Новый CTest `reference_city_coplanar_impacts` проверяет
10 сценариев, включая оба цвета и направления выстрела,
перестановку слотов, две независимые пары врагов,
пограничный счётчик оглушения и 650 кадров воспроизводимости.

SDL2 `COPLANAR_IMPACTS_SDL_PASS` выводит двух синтетических
врагов с одинаковым X, но разными диапазонами Y, затем
проверяет два реальных синих ARGB8888-пикселя оглушения,
которые принадлежат разным персонажам.

Эта семантика создана для собственного технического
прототипа без ресурсов оригинального QuackShot.
Новые CTest и SDL2 работают на хосте. Сборка NRO и
гостевой запуск в NeXium проверяются отдельно.
